## 1. 개념부터 이해하기

먼저 우리가 흔히 쓰는 파이썬 리스트(배열)와 비교해서 생각해보면 이해하기 쉬워요.

**배열(리스트)**: 데이터들이 메모리에 **일렬로 붙어서** 저장돼요. 마치 아파트 호실처럼 순서대로 딱딱 붙어있는 느낌이에요.

**연결 리스트**: 데이터들이 메모리 여기저기 **흩어져** 있어요. 대신 각 데이터가 "다음 데이터가 어디 있는지" 주소(포인터)를 들고 있어요. 마치 보물찾기처럼, 첫 번째 힌트를 찾으면 그 안에 "다음 힌트는 여기 있어"라는 쪽지가 들어있는 구조예요.

```
[값: 1 | 다음 주소] → [값: 2 | 다음 주소] → [값: 3 | 다음 주소] → None
```

이렇게 하나의 데이터 덩어리를 **노드(Node)**라고 부르고, 노드는 두 가지 정보를 가져요:

- **data**: 실제 저장하고 싶은 값
- **next**: 다음 노드를 가리키는 참조(포인터)

## 2. 노드(Node) 클래스 만들기

```python
class Node:
    def __init__(self, data):
        self.data = data   # 데이터 저장
        self.next = None   # 다음 노드 주소 (처음엔 아무데도 안 가리킴)
```

노드 하나를 만들어보면:

```python
node1 = Node(1)
print(node1.data)  # 1
print(node1.next)  # None (아직 연결된 다음 노드가 없음)
```

## 3. 노드들을 연결해보기

```python
node1 = Node(1)
node2 = Node(2)
node3 = Node(3)

# 수동으로 연결하기
node1.next = node2   # node1이 node2를 가리킴
node2.next = node3   # node2가 node3를 가리킴
# node3.next는 그대로 None (마지막 노드니까)

# 확인해보기
print(node1.data)        # 1
print(node1.next.data)   # 2  (node1의 다음 노드의 데이터)
print(node1.next.next.data)  # 3  (그 다음 노드의 데이터)
```

여기서 핵심은 `node1.next.next.data`처럼 **next를 타고타고 들어가야** 다음 값에 접근할 수 있다는 점이에요. 배열처럼 `list[2]`로 바로 못 가요.

## 4. LinkedList 클래스로 정리하기

매번 이렇게 수동으로 연결하는 건 불편하니까, 관리해주는 클래스를 만들어요.

```python
class LinkedList:
    def __init__(self):
        self.head = None   # 첫 번째 노드를 가리키는 시작점

    # 맨 뒤에 데이터 추가하기
    def append(self, data):
        new_node = Node(data)
        
        if self.head is None:      # 리스트가 비어있으면
            self.head = new_node   # 새 노드가 곧 head
            return
        
        # 비어있지 않으면 마지막 노드까지 이동
        current = self.head
        while current.next is not None:
            current = current.next
        
        current.next = new_node    # 마지막 노드의 next에 새 노드 연결

    # 전체 출력하기
    def print_list(self):
        current = self.head
        while current is not None:
            print(current.data, end=" -> ")
            current = current.next
        print("None")
```

사용해보기:

```python
ll = LinkedList()
ll.append(1)
ll.append(2)
ll.append(3)

ll.print_list()   # 1 -> 2 -> 3 -> None
```

**동작 원리 (append 메서드)**: `head`부터 시작해서 `current.next`가 `None`일 때까지(=마지막 노드에 도착할 때까지) 계속 다음 칸으로 이동해요. 마지막 노드를 찾으면 그 노드의 `next`에 새 노드를 연결해요.

## 5. 자주 쓰는 기능 추가하기

```python
class LinkedList:
    def __init__(self):
        self.head = None

    def append(self, data):
        new_node = Node(data)
        if self.head is None:
            self.head = new_node
            return
        current = self.head
        while current.next is not None:
            current = current.next
        current.next = new_node

    # 맨 앞에 추가하기
    def prepend(self, data):
        new_node = Node(data)
        new_node.next = self.head   # 새 노드가 기존 head를 가리키게 하고
        self.head = new_node        # head를 새 노드로 교체

    # 특정 값 삭제하기
    def delete(self, data):
        if self.head is None:
            return
        
        if self.head.data == data:      # 삭제할 값이 head일 때
            self.head = self.head.next  # head를 다음 노드로 교체
            return
        
        current = self.head
        while current.next is not None:
            if current.next.data == data:
                current.next = current.next.next  # 앞뒤 노드를 직접 연결 (중간 노드 건너뛰기)
                return
            current = current.next

    def print_list(self):
        current = self.head
        while current is not None:
            print(current.data, end=" -> ")
            current = current.next
        print("None")
```

테스트:

```python
ll = LinkedList()
ll.append(1)
ll.append(2)
ll.append(3)
ll.print_list()      # 1 -> 2 -> 3 -> None

ll.prepend(0)
ll.print_list()      # 0 -> 1 -> 2 -> 3 -> None

ll.delete(2)
ll.print_list()      # 0 -> 1 -> 3 -> None
```

**삭제(delete)의 핵심 아이디어**: 삭제하고 싶은 노드 자체를 건드리는 게 아니라, **그 노드를 가리키던 이전 노드의 next를, 삭제할 노드의 next로 바꿔치기**해요. 그러면 삭제된 노드는 아무도 가리키지 않게 되어 사실상 리스트에서 빠지게 돼요.

```
삭제 전: 1 -> 2 -> 3
삭제 후: 1 --------> 3   (2는 그냥 붕 떠서 안 쓰이게 됨)
```

## 6. 배열이랑 비교하면 왜 쓰는지 감이 와요

| |배열(리스트)|연결 리스트|
|---|---|---|
|특정 위치 접근|빠름 (바로 인덱스로)|느림 (앞에서부터 next 타고 가야 함)|
|맨 앞에 삽입/삭제|느림 (다 한 칸씩 밀려야 함)|빠름 (연결만 바꾸면 됨)|
|메모리|연속된 공간 필요|여기저기 흩어져도 됨|

**핵심 요약**: 연결 리스트는 "값 + 다음 위치 정보"를 가진 노드들이 화살표(참조)로 사슬처럼 이어진 구조이고, 무언가에 접근하려면 항상 `head`부터 `next`를 따라가야 한다는 것만 기억하면 개념은 다 잡힌 거예요!
