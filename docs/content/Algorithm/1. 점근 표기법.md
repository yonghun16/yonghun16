# 1. 점근 표기법

## 핵심 아이디어

컴퓨터 프로그램이 "얼마나 빠른지/느린지"를 말할 때, 입력값 n이 **아주 커졌을 때** 그 함수가 대략 어떤 속도로 증가하는지만 보겠다는 게 점근적 표기법의 목적이에요. 작은 차이(상수, 낮은 차수 항)는 다 무시하고 "제일 큰 흐름"만 보는 거죠.

예시로 쓰인 식은 `n³ + n² + n - 1` 인데, n이 무한히 커지면 결국 `n³` 항이 나머지를 압도해버려서, 나머지 항들(n², n, -1)은 있으나 마나 하게 됩니다.

## 세 가지 표기법

**1. O (빅-오) — "최악의 경우, 상한선"**

- "이 함수는 최대 이 정도 속도로 커진다"는 뜻이에요.
- `n³ + n² + n - 1`은 `O(n³)`으로 표현합니다 (제일 정확한 상한).
- 비유: "나는 시험을 100점보다 낮게 받는다"라고 말하는 것과 비슷해요. 사실이지만, 더 타이트하게 "90점보다 낮다"고 말하는 게 더 유용한 정보를 줍니다.

**2. Ω (빅-오메가) — "최선의 경우, 하한선"**

- "이 함수는 최소 이 정도 속도로는 커진다"는 뜻이에요.
- O와 반대 개념: 상한이 아니라 하한을 말합니다.

**3. Θ (빅-세타) — "정확한 성장 속도"**

- 상한(O)과 하한(Ω)이 **동시에 딱 맞아떨어지는** 경우예요.
- `n³ + n² + n - 1`은 `Θ(n³)`로 표현 — "정확히 n³ 속도로 커진다"는 가장 정밀한 표현입니다.

## 비유로 정리하면

어떤 사람의 걷는 속도를 설명한다고 해봅시다:

- **O(빅오)**: "시속 10km보다는 느리다" (상한 — 최악이라도 이 정도)
- **Ω(빅오메가)**: "시속 2km보다는 빠르다" (하한 — 최소한 이 정도는 된다)
- **Θ(빅세타)**: "시속 정확히 5km다" (상한과 하한이 일치 — 정확한 값)

## 상수 무시가 왜 중요한가

`9n³ - 2`도 그냥 `O(n³)`이라고 씁니다. 왜냐면 n이 100만, 1억쯤 되면 앞에 곱해진 9는 별로 중요하지 않고, "세제곱 속도로 커진다"는 큰 그림만 중요하기 때문이에요. 이게 알고리즘 분석에서 상수를 다 무시하는 이유입니다.

**요약**: 이 세 표기법은 알고리즘이 입력 크기가 커질 때 얼마나 빠르게 느려지는지를 "대략적인 등급"으로 매기는 도구이고, O는 상한, Ω는 하한, Θ는 정확한 등급을 말하는 거예요.

### 숫자로 보기: n³ 항이 왜 다 잡아먹나

`n³ + n² + n - 1` 식에 실제 숫자를 넣어봅시다.

|n|n³ (제일 큰 항)|n² + n - 1 (나머지)|전체 값|n³이 차지하는 비중|
|---|---|---|---|---|
|10|1,000|109|1,109|약 90%|
|100|1,000,000|10,099|1,010,099|약 99%|
|10,000|1,000,000,000,000|100,009,999|1,000,100,009,999|약 99.99%|

n이 커질수록 뒤에 붙은 n², n, -1은 **점점 더 무의미해집니다.** 그래서 "이 식은 대략 n³처럼 움직인다"고 퉁쳐서 말하는 거예요. 이게 바로 O(n³), Θ(n³)의 의미입니다.

### 일상 비유: 이삿짐 나르기

박스 n개를 옮기는 데 걸리는 시간이라고 생각해봐요.

- **실제 걸리는 시간** = "박스 1개당 3분" + "엘리베이터 기다리는 시간 10분" + "쉬는 시간 5분"
- 박스가 5개면: 15분 + 10분 + 5분 = 30분 (대기시간·휴식이 꽤 비중 있음)
- 박스가 1000개면: 3000분 + 10분 + 5분 ≈ 3015분 (대기시간·휴식은 있으나 마나)

→ 박스가 아주 많아지면 결국 **"박스 개수 × 3분"**이 전체 시간을 결정합니다. 엘리베이터 기다리는 시간, 쉬는 시간은 무시해도 될 만큼 작아지죠. 이게 상수(10분, 5분)를 무시하는 이유예요.

### O, Ω, Θ를 다시 이 비유로

- **O (상한)**: "아무리 오래 걸려도 박스당 5분을 넘기진 않는다" → 최악의 경우를 보장
- **Ω (하한)**: "아무리 빨라도 박스당 1분보다 빠르진 않는다" → 최선의 경우를 보장
- **Θ (정확한 값)**: "박스당 정확히 3분씩 걸린다" → 상한과 하한이 딱 맞아떨어지는 가장 정밀한 표현

정리하면: **점근적 표기법은 "n이 어마어마하게 커졌을 때, 결국 무엇이 전체 시간을 좌우하는가"만 보는 것**이고, O/Ω/Θ는 그걸 상한/하한/정확한 값으로 각각 표현하는 방법이에요.

점근적 표기법 문제는 결국 **최고차항의 차수를 비교**하는 문제예요.

- deg(f) > deg(g) → f가 g보다 빨리 큼 → **f = Ω(g)** 성립, **f = O(g)는 거짓**
- deg(f) < deg(g) → f가 g보다 느리게 큼 → **f = O(g)** 성립, **f = Ω(g)는 거짓**
- deg(f) = deg(g) → 같은 속도로 큼 → **f = O(g), f = Ω(g), f = Θ(g) 모두 성립**
