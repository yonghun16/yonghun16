## 변수 (Variables)

```bash
# 변수 선언 (공백 없음)
name="Song"
age=30

# 변수 사용 ($ 붙임)
echo $name              # Song
echo ${name}            # Song (중괄호는 변수명 명확히 할 때)

# 환경변수 확인
echo $HOME              # /home/user
echo $PATH              # 실행 경로
echo $PWD               # 현재 경로

# 읽기 전용 변수
readonly VERSION="1.0"
# VERSION="2.0"        # 오류 발생

# 모든 변수 나열
set
```

## 리다이렉션 (Redirection)

```bash
# 표준 출력(stdout) → 파일 (덮어쓰기)
echo "Hello" > output.txt

# 표준 출력 → 파일 (추가)
echo "World" >> output.txt

# 표준 에러(stderr) → 파일
ls /nonexistent 2> error.txt

# 표준 출력 + 에러 → 파일
command > output.txt 2>&1

# 파일 → 표준 입력 (stdin)
cat < input.txt

# 여러 명령어 한번에 실행
cat << EOF
첫 번째 줄
두 번째 줄
EOF
```

## 파이프 (Pipe)

| 사용법 | 설명 | 예시 |
|--------|------|------|
| `\|` | 앞 명령어 출력 → 뒤 명령어 입력 | `cat file.txt \| grep "keyword"` |
| `\|\|` | OR 연산자 (앞이 실패하면 뒤 실행) | `command1 \|\| command2` |
| `&&` | AND 연산자 (앞이 성공하면 뒤 실행) | `command1 && command2` |
| `;` | 순차 실행 (앞의 성공 여부 무관) | `command1 ; command2` |

### 파이프 실제 예시
```bash
# 파일에서 특정 줄 찾기
cat users.txt | grep "admin"

# 단어 수 세기
echo "hello world" | wc -w              # 2

# 결과 정렬 후 중복 제거
cat file.txt | sort | uniq

# 여러 명령어 연결
ps aux | grep "node" | wc -l

# 도메인별 로그 분류
cat access.log | grep "error" | sort | uniq -c | sort -rn
```

## 명령어 치환 (Command Substitution)

```bash
# 백틱 또는 $() 사용
today=$(date +%Y-%m-%d)
echo "Today is $today"

# 파일 개수 저장
file_count=$(ls | wc -l)
echo "Files: $file_count"

# 한 번에 여러 작업
echo "User: $(whoami), Path: $(pwd)"
```

## 산술 연산

```bash
# $(( )) 또는 let 사용
result=$((10 + 5))
echo $result                # 15

# 다양한 연산
echo $((20 - 3))           # 17
echo $((4 * 5))            # 20
echo $((100 / 4))          # 25
echo $((17 % 5))           # 2 (나머지)

# 변수를 이용한 계산
a=10
b=3
echo $(($a + $b))          # 13
```

## 조건문 (if)

```bash
# 파일 존재 여부 확인
if [ -f "file.txt" ]; then
    echo "파일이 존재합니다"
else
    echo "파일이 없습니다"
fi

# 문자열 비교
if [ "$name" = "Song" ]; then
    echo "맞습니다"
fi

# 숫자 비교
if [ $age -gt 25 ]; then
    echo "25세 이상입니다"
fi

# 여러 조건 (AND: -a, OR: -o)
if [ -f "file.txt" ] && [ -r "file.txt" ]; then
    echo "파일이 있고 읽을 수 있습니다"
fi
```

## 반복문 (Loop)

```bash
# for 루프
for i in 1 2 3 4 5; do
    echo "번호: $i"
done

# 범위 루프
for i in {1..10}; do
    echo $i
done

# while 루프
counter=1
while [ $counter -le 5 ]; do
    echo $counter
    counter=$((counter + 1))
done

# 파일 목록 처리
for file in *.txt; do
    echo "처리: $file"
done
```

## 함수 (Functions)

```bash
# 함수 정의
greet() {
    echo "Hello, $1!"
}

# 함수 호출
greet "Song"               # Hello, Song!

# 반환값 있는 함수
add() {
    return $(($1 + $2))
}

add 5 3
echo $?                    # 8 (마지막 명령어 반환값)

# 변수에 저장
result=$((5 + 3))
echo "합: $result"
```

## 실전 예시

```bash
# 1. 백업 스크립트
backup_dir="backup-$(date +%Y%m%d)"
mkdir -p $backup_dir
cp -r project/ $backup_dir/
echo "백업 완료: $backup_dir"

# 2. 특정 파일 찾아서 삭제
for file in $(find . -name "*.log" -type f); do
    rm -f "$file"
    echo "삭제: $file"
done

# 3. 서버 상태 체크
if ping -c 1 192.168.1.1 > /dev/null 2>&1; then
    echo "서버 온라인"
else
    echo "서버 오프라인" >> status.log
fi

# 4. 텍스트 처리
cat data.txt | \
    grep "ERROR" | \
    cut -d',' -f2 | \
    sort | uniq -c | \
    sort -rn
```
