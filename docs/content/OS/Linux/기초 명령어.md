# 리눅스 기초 명령어

## 파일 및 디렉토리 관리

| 명령어 | 설명 | 예시 |
|--------|------|------|
| `ls` | 파일/폴더 목록 | `ls -la` (숨김파일 포함, 상세) |
| `cd` | 디렉토리 이동 | `cd /home/user`, `cd ..` (상위로) |
| `pwd` | 현재 경로 출력 | `pwd` |
| `mkdir` | 폴더 생성 | `mkdir project` |
| `rmdir` | 빈 폴더 삭제 | `rmdir project` |
| `rm` | 파일/폴더 삭제 | `rm file.txt`, `rm -r folder` |
| `cp` | 파일/폴더 복사 | `cp file.txt file_copy.txt` |
| `mv` | 파일/폴더 이동 또는 이름변경 | `mv old.txt new.txt` |
| `touch` | 빈 파일 생성 | `touch test.txt` |

## 파일 내용 확인

| 명령어 | 설명 | 예시 |
|--------|------|------|
| `cat` | 파일 전체 내용 출력 | `cat file.txt` |
| `less` | 파일 내용 페이징 | `less file.txt` (스페이스로 넘기기) |
| `head` | 파일 처음 10줄 | `head -20 file.txt` (처음 20줄) |
| `tail` | 파일 마지막 10줄 | `tail -f file.txt` (실시간 감시) |
| `grep` | 텍스트 검색 | `grep "keyword" file.txt` |

## 사용자 및 권한

| 명령어 | 설명 | 예시 |
|--------|------|------|
| `sudo` | 관리자 권한 실행 | `sudo apt update` |
| `whoami` | 현재 사용자명 | `whoami` |
| `chmod` | 파일 권한 변경 | `chmod 755 script.sh` (실행권한) |
| `chown` | 파일 소유자 변경 | `chown user:group file.txt` |

## 시스템 정보

| 명령어 | 설명 | 예시 |
|--------|------|------|
| `df` | 디스크 공간 | `df -h` (사람이 읽기 쉬운 형식) |
| `du` | 폴더 크기 | `du -sh folder` |
| `ps` | 실행 중인 프로세스 | `ps aux` |
| `top` | 실시간 프로세스 모니터링 | `top` |
| `uname` | 시스템 정보 | `uname -a` |

## 네트워크 및 연결

| 명령어    | 설명       | 예시                                  |
| ------ | -------- | ----------------------------------- |
| `ping` | 서버 응답 확인 | `ping google.com`                   |
| `curl` | URL 요청   | `curl https://example.com`          |
| `wget` | 파일 다운로드  | `wget https://example.com/file.zip` |
| `ssh`  | 원격 서버 접속 | `ssh user@192.168.1.1`              |

## 패키지 관리 (Ubuntu/Debian)

```bash
sudo apt update         # 패키지 목록 업데이트
sudo apt install pkg   # 패키지 설치
sudo apt remove pkg    # 패키지 제거
sudo apt upgrade       # 전체 업그레이드
```
