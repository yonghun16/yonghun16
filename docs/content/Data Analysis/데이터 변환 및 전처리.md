## 전체 흐름

전처리는 네 단계로 이어지며, 각 단계의 결과를 다음 단계가 그대로 받습니다.

1. 수집: `requests.get`으로 API를 호출하고 응답을 `response.json()`으로 읽는다.
2. 변환: 응답 안의 `items.item` 리스트를 `pd.DataFrame`으로 바꾼다. (문 2-1)
3. 전처리: `exmn_ymd`에서 `year`, `season` 컬럼을 추가한다. (문 2-2)
4. 확인: `head`, `info`로 결과가 맞는지 본다.

## JSON을 DataFrame으로 변환

API 응답의 데이터 본체는 `response → body → items → item` 순서로 들어 있는 딕셔너리 리스트이고, 이 리스트를 `pd.DataFrame`에 넘기면 표가 됩니다.

```python
import pandas as pd

body = response.json()["response"]["body"]
items = body["items"]["item"]   # [{...}, {...}, ...] 형태
df = pd.DataFrame(items)
```

- 리스트 안 딕셔너리 하나가 한 행, 딕셔너리의 키가 컬럼이 됩니다.
- `body["totalCount"]`로 전체 건수(66건)를 확인하고, `numOfRows`(200)가 건수보다 크면 한 번의 호출로 다 받습니다.

## 날짜 전처리: year와 season 추가

`exmn_ymd`는 `"20150512"` 같은 문자열이므로 모두 날짜형으로 바꾼 뒤 연도와 월을 꺼내 쓰면 됩니다.

```python
SEASON_BY_MONTH = {
    3: "봄", 4: "봄", 5: "봄",
    6: "여름", 7: "여름", 8: "여름",
    9: "가을", 10: "가을", 11: "가을",
    12: "결울", 1: "결울", 2: "결울",
}

dates = pd.to_datetime(df["exmn_ymd"], format="%Y%m%d")

df["year"] = dates.dt.year
df["season"] = dates.dt.month.map(SEASON_BY_MONTH)
```

- `pd.to_datetime(..., format="%Y%m%d")`: 8자리 문자열을 datetime으로 바꾼다. 형식을 적어 두면 해석 오류가 없고 빠르다.
- `.dt` 접근자: datetime 컴럼에서 `.dt.year`, `.dt.month`처럼 값을 꺼낸다.
- `.map(딕셔너리)`: 월(숫자)을 계절 이름으로 한 번에 바꾼다. 행마다 `for`와 `if/elif`를 돌리는 대신 컴럼 전체에 적용하는 방식이다.
- 결울(12\~2월)처럼 연도를 넘나드는 구간도 딕셔너리에는 월 12개만 적으면 되므로 조건식이 필요 없다.

## 열 추가 결과 확인

`print(df.head())`로 맨 오른쪽에 `year`와 `season`이 붙었는지 확인합니다.

- 변환 전 출력의 `[5 rows x 20 columns]`가 변환 후 `[5 rows x 22 columns]`로 바뀌면 컬럼 2개가 정상적으로 추가된 것입니다.
- 컬럼이 많으면 가운데가 `...`으로 생략되어 보입니다. 새 컬럼은 항상 맨 오른쪽에 붙으니 거기서 찾으면 됩니다.
