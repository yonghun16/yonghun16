## 두 문제의 목표와 코드 흐름

3-1은 연도별 평균 가격을 선 그래프로, 3-2는 계절별 평균 가격을 막대 그래프로 그리는 문제이며, 둘 다 집계 → 그래프 → 저장 순서로 풀립니다.

| 문제 | 묶는 기준 | 그래프 | 사용한 데이터 |
| --- | --- | --- | --- |
| 3-1 | `year` (연도) | 선 그래프 (`plot`) | `df` (봄배추, 2015\~2025) |
| 3-2 | `season` (계절) | 막대 그래프 (`bar`) | `df_all` (품종 조건 없이 받은 전체 배추) |

1. 집계: `groupby`로 연도 또는 계절별 평균을 구한다.
2. 그래프: `matplotlib`으로 선 또는 막대를 그린다.
3. 저장: `savefig`로 PNG 파일을 저장하고 `show`로 화면에 띄운다.

3-1은 그래프 제목에 학번 뒤 4자리를 넣어 저장해야 한다는 조건이 있습니다.

## 그래프 전에 하는 집계

그래프를 그리기 전에 가격을 숫자로 바꾸고, 연도나 계절별로 묶어 평균을 구해야 합니다.

```python
# API 값은 문자열이므로 숫자로 변환해야 평균을 구할 수 있다.
df["exmn_dd_prc"] = pd.to_numeric(df["exmn_dd_prc"])

yearly_mean = df.groupby("year")["exmn_dd_prc"].mean()      # 3-1
seasonal_mean = df_all.groupby("season")["exmn_dd_prc"].mean()  # 3-2
```

- `pd.to_numeric`: 문자열 컬럼을 숫자로 바꾼다. 이 줄이 없으면 `.mean()`에서 `TypeError`가 난다.
- `groupby("year")`: 같은 연도끼리 행을 묶는다. 결과의 인덱스(행 이름)가 연도가 된다.
- `["exmn_dd_prc"].mean()`: 묶인 그룹마다 가격 컬럼의 평균을 구한다.
- 결과는 인덱스가 연도(또는 계절)인 Series라서 `.index`는 x축 값, `.values`는 y축 값으로 쓴다.

## 문 3-1: 연도별 평균 가격 선 그래프

연도를 x축, 평균 가격을 y축으로 `ax.plot`에 넘기면 선 그래프가 되고, 제목에 학번 뒤 4자리를 f-string으로 넣습니다.

```python
STUDENT_ID_LAST4 = "4372"

fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(yearly_mean.index, yearly_mean.values, marker="o")
ax.set_title(f"연도별 배추 평균 가격 변화 - {STUDENT_ID_LAST4}")
ax.set_xlabel("연도")
ax.set_ylabel("평균 가격 (exmn_dd_prc)")
ax.set_xticks(yearly_mean.index)
ax.grid(True, alpha=0.3)

fig.savefig(f"q3_1_cabbage_yearly_price_{STUDENT_ID_LAST4}.png", dpi=150, bbox_inches="tight")
plt.show()
```

- `plt.subplots(figsize=(8, 5))`: 그림 전체(`fig`)와 그래프를 그리는 영역(`ax`)을 만든다. 크기는 가로 8, 세로 5(인치)다.
- `ax.plot(x, y, marker="o")`: 점을 선으로 잇고, 각 점에 동그라미를 찍는다.
- `ax.set_xticks(yearly_mean.index)`: 눈금을 데이터에 있는 연도로만 정한다. 이 줄이 없으면 2015.5 같은 소수 눈금이 생길 수 있다.
- f-string `f"... - {STUDENT_ID_LAST4}"`: 변수 값을 문자열 안에 끼워 넣는다. 제목과 파일 이름에 학번을 한 번만 적으면 둘 다 바뀐다.
- `savefig`는 `show` 앞에 둔다. `show`를 먼저 호출하면 창을 닫을 때 그림이 지워져 빈 파일이 저장될 수 있다.

## 문 3-2: 계절별 평균 가격 막대 그래프

계절을 봄\~겨울 순서로 고정한 뒤 `ax.bar`로 막대를 그리고, `ax.bar_label`로 막대마다 평균값을 숫자로 표시합니다.

```python
SEASON_ORDER = ["봄", "여름", "가을", "겨울"]

seasonal_mean = df_all.groupby("season")["exmn_dd_prc"].mean().reindex(SEASON_ORDER)

fig2, ax2 = plt.subplots(figsize=(8, 5))
bars = ax2.bar(seasonal_mean.index, seasonal_mean.values)
ax2.bar_label(bars, labels=[f"{v:,.0f}" for v in seasonal_mean], padding=3)

ax2.set_title(f"계절별 배추 평균 가격 - {STUDENT_ID_LAST4}")
ax2.set_xlabel("계절")
ax2.set_ylabel("평균 가격 (exmn_dd_prc)")
ax2.grid(axis="y", alpha=0.3)
```

- `reindex(SEASON_ORDER)`: 인덱스를 지정한 순서로 다시 배열한다. 이 줄이 없으면 막대가 가나다순(가을, 겨울, 봄, 여름)으로 나온다. 데이터에 없는 계절은 `NaN`으로 채워진다.
- `ax2.bar(x, y)`: x 위치마다 y 높이의 막대를 그린다. 반환값 `bars`를 `bar_label`에 넘긴다.
- `ax2.bar_label(bars, labels=..., padding=3)`: 각 막대 위에 글자를 붙인다. `padding`은 막대 끝과 글자 사이 간격이다.
- `f"{v:,.0f}"`: 숫자를 천 단위 쉼표를 넣고 소수점 없이 문자열로 만든다. 8688.2는 `8,688`이 된다.
- `[ ... for v in seasonal_mean]`: 리스트 컴프리헨션이다. 계절별 평균값 4개를 하나씩 꺼내 글자로 바꿔 리스트로 만든다.
- `grid(axis="y")`: 가로 눈금선만 그린다. 막대 그래프는 세로 눈금선이 필요 없다.

## 한글 폰트 설정과 그래프 저장

matplotlib의 기본 글꼴에는 한글이 없어서, 제목과 축 이름이 네모(□)로 깨지지 않게 폰트를 한 번 지정해야 합니다.

```python
# 한글 폰트 (macOS). 윈도우는 "Malgun Gothic"으로 변경
plt.rcParams["font.family"] = "AppleGothic"
plt.rcParams["axes.unicode_minus"] = False
```

- `font.family`: 그래프 전체에 쓸 글꼴을 정한다. 파일 맨 위에 한 번만 두면 3-1, 3-2 모두에 적용된다.
- `axes.unicode_minus = False`: 한글 폰트에서 음수 부호(−)가 깨지는 것을 막는다.
- `fig.savefig(파일명, dpi=150, bbox_inches="tight")`: PNG로 저장한다. `dpi`는 해상도, `bbox_inches="tight"`는 글자가 잘리지 않게 여백을 자동으로 맞춘다.
- 저장 파일은 코드를 실행한 폴더에 생긴다. 파일 이름에 학번을 넣어 두면 어느 문제의 결과인지 헷갈리지 않는다.

## 자주 만난 에러와 원인

에러 메시지를 읽고 원인이 데이터인지 코드인지 먼저 가르면 대부분 한두 줄로 해결됩니다.

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| `TypeError: dtype 'str' does not support operation 'mean'` | 가격 컬럼이 문자열이라 평균을 못 구함 | `groupby` 앞에 `pd.to_numeric` 변환 |
| 선 그래프 x축에 2015만 보임 | 수집 기간이 2015년뿐이라 `groupby("year")` 결과가 1개 | 조회 기간 `LTE`를 2025년 말로 확대 |
| 뒤쪽 연도가 빠지고 앞 연도만 나옴 | 한 번에 받는 건수(`numOfRows`) 제한으로 날짜순 앞부분만 수집 | `numOfRows`를 키우고 `len(items)`와 `totalCount`를 비교 |
| 가을·겨울이 `NaN`으로 출력됨 | 봄배추(`vrty_cd=01`) 데이터에는 봄·여름 기록만 있어 `reindex`가 빈 값으로 채움 | 품종 조건 없이 받은 전체 배추 데이터로 계산 |
| 제목과 축 글자가 네모(□)로 깨짐 | 한글 폰트를 지정하지 않음 | `plt.rcParams["font.family"]` 설정 |
| `SERVICE_KEY = ()`로 인증 오류 | 따옴표를 지워 빈 튜플이 되어 요청에 키가 빠짐 | 비울 때도 `""`를 남긴다 |
| 에디터에 빨간 줄(타입 경고) | 에디터가 결과 타입을 확정하지 못해 띄우는 경고 | 실행 에러가 아니므로 무시해도 됨 |

에러는 숫자나 메시지 한 줄에 원인이 들어 있습니다. `print(df["season"].value_counts())`, `print(len(items), body["totalCount"])`처럼 중간값을 찍어 보면 어디서 어긋났는지 바로 보입니다.

## 핵심 요약과 확인 문제

집계는 `to_numeric` → `groupby` → `mean`, 선 그래프는 `ax.plot`, 막대 그래프는 `reindex` → `ax.bar` → `ax.bar_label`, 저장은 `savefig`(`show` 앞)로 기억하면 됩니다.

**확인 문제**

1. 가격 컬럼을 `pd.to_numeric`으로 바꾸지 않고 `.mean()`을 부르면 어떤 에러가 나는가?
2. 막대 그래프에서 `reindex(SEASON_ORDER)`를 빼면 막대 순서는 어떻게 되는가?
3. 봄배추 데이터로 계절별 평균을 내면 가을과 겨울은 어떻게 나오고, 왜 그런가?
4. `fig.savefig(...)`를 `plt.show()` 뒤에 두면 어떤 문제가 생길 수 있는가?
5. 숫자 `8688.2`를 천 단위 쉼표와 소수점 없이 문자열로 만드는 f-string 표현은?

**정답**

1. `TypeError: dtype 'str' does not support operation 'mean'`. 문자열에는 평균 연산이 없다.
2. 가나다순(가을, 겨울, 봄, 여름)으로 나온다.
3. `NaN`으로 나온다. 봄배추 데이터에는 봄·여름 기록만 있어서 가을·겨울 그룹이 없고, `reindex`가 빈 값으로 채운다.
4. 창을 닫을 때 그림이 지워져 빈 그림이 저장될 수 있다. `savefig`를 먼저 호출한다.
5. `f"{8688.2:,.0f}"` → `8,688`
