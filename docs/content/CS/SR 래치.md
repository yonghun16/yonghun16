# SR 래치 자세히 보기

## 1. 기본 구조: 교차 결합된 두 게이트

SR 래치는 게이트 두 개의 출력을 서로의 입력으로 되돌려 연결한 **교차 결합(cross-coupled)** 회로입니다. 핵심은 피드백입니다. 한쪽 출력이 다른 쪽 게이트의 입력이 되므로, 회로가 **안정된 상태를 두 가지** 가질 수 있습니다.

- 상태 A: Q = 1, Q̄ = 0
- 상태 B: Q = 0, Q̄ = 1

입력을 모두 0으로 두면 회로는 이 둘 중 하나에 머뭅니다. 이것이 1비트를 기억하는 원리입니다.

## 2. NOR 게이트 버전의 동작

회로식은 다음과 같습니다.

- Q = NOR(R, Q̄)
- Q̄ = NOR(S, Q)

NOR는 입력이 모두 0일 때만 1을 출력하고, 입력 중 하나라도 1이면 0을 출력합니다. 이 성질을 기준으로 각 경우를 따라가 보겠습니다.

**(a) 설정 (Set): S=1, R=0**  
초기 상태를 Q=0, Q̄=1이라고 두면 다음과 같이 진행됩니다.

1. Q̄ = NOR(1, 0) = 0
2. Q = NOR(0, 0) = 1
3. 이제 Q=1이므로 Q̄ = NOR(S, 1) = 0 이 되어 안정됩니다.

**(b) 설정 해제: S=0, R=0 으로 되돌림**  
Q=1이 Q̄의 입력으로 들어가 Q̄ = NOR(0, 1) = 0을 유지하고, Q = NOR(0, 0) = 1도 유지됩니다. 따라서 **입력을 떼도 Q=1이 그대로 남습니다.** 이것이 기억 동작입니다.

**(c) 리셋 (Reset): S=0, R=1**

1. Q = NOR(1, Q̄) = 0
2. Q̄ = NOR(0, 0) = 1  
    이 상태도 입력을 떼면 그대로 유지됩니다.

## 3. 금지 상태 S=1, R=1

두 입력을 동시에 1로 만들면 다음과 같습니다.

- Q = NOR(1, Q̄) = 0
- Q̄ = NOR(1, Q) = 0

두 출력이 모두 0이 되어 Q̄ = not Q라는 상보 관계가 깨집니다. 문제는 여기서 입력을 동시에 0으로 풀 때 생깁니다.

입력을 0으로 되돌리면 두 게이트 모두 "입력이 0인데 상대 출력도 0"을 보므로 출력을 1로 올리려 합니다. 두 출력이 같은 시점에 1로 바뀌면 서로를 다시 0으로 끌어내리는 상황이 반복될 수 있습니다. 게이트마다 지연 시간이 조금씩 달라서 어느 쪽이 먼저 1이 되는지에 따라 최종 상태가 **레이스(race)** 로 결정됩니다. 어떤 경우에는 발진하거나 **준안정(metastable)** 상태에 머물기도 합니다. 그래서 설계에서는 S=R=1 입력을 금지합니다.

## 4. 특성 방정식과 여기표

NOR 기반 SR 래치의 다음 상태는 다음과 같이 쓸 수 있습니다. 단 S·R=0 조건에서만 성립합니다.

**Q⁺ = S + R̄·Q**

|S|R|Q⁺ (다음 상태)|
|:-:|:-:|:-:|
|0|0|Q (유지)|
|1|0|1|
|0|1|0|
|1|1|금지|

## 5. NAND 게이트 버전

NAND로 만들면 입력이 **액티브 로우**가 됩니다. 입력을 0일 때 동작하도록 S̄, R̄라고 표기합니다.

- Q = NAND(S̄, Q̄)
- Q̄ = NAND(R̄, Q)

|S̄|R̄|동작|
|:-:|:-:|:-:|
|1|1|유지|
|0|1|설정 (Q=1)|
|1|0|리셋 (Q=0)|
|0|0|금지|

NAND 버전은 실제 칩에서 자주 쓰입니다. 정상 동작은 NOR 버전과 같고 입력만 반전된 형태입니다.

## 6. 게이트형 SR 래치 (Gated SR Latch)

기본 SR 래치는 입력이 바뀌는 즉시 출력이 따라 바뀝니다. 이를 제어하기 위해 **인에이블 신호 E**를 추가한 것이 게이트형 SR 래치입니다.

- S' = S·E, R' = R·E 로 입력을 먼저 걸러냅니다.
- E=0이면 S, R이 무엇이든 래치는 **유지** 상태가 됩니다.
- E=1이면 기본 SR 래치처럼 동작합니다.

이렇게 하면 여러 래치의 동작 시점을 한꺼번에 맞출 수 있습니다. 다만 E=1인 동안에는 입력 변화가 그대로 출력에 반영되는 **투명(transparent)** 상태라는 한계가 있습니다. 이 점을 개선한 것이 D 래치와 플립플롭입니다.

## 7. 실제 활용 예: 스위치 바운싱 제거

기계식 스위치를 누르면 접점이 여러 번 튀면서 짧은 시간에 0과 1이 반복됩니다. 이를 바운싱이라고 합니다. 이때 SR 래치를 사용하면 이 노이즈를 걸러낼 수 있습니다.

SPDT(양투) 스위치의 한쪽 단자는 S̄에, 다른 쪽 단자는 R̄에 연결합니다. 스위치가 한쪽으로 넘어가면 래치가 한 번 바뀌고, 그 뒤 접점이 튀더라도 그 입력이 새로운 상태를 유지하도록 하기 때문에 출력은 깔끔하게 한 번만 전환됩니다.

## 8. 정리

- SR 래치는 교차 결합된 게이트의 피드백으로 1비트를 기억합니다.
- 설정과 리셋은 입력 한 번으로 이루어지고, 입력을 떼도 상태가 유지됩니다.
- S=R=1 조합은 출력이 상보 관계를 잃고, 입력을 풀 때 레이스로 인해 결과를 예측할 수 없습니다.
- 클럭 제어와 입력 동기화가 필요하면 게이트형 래치, D 래치, 플립플롭으로 발전시킵니다.
