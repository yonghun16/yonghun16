 which나 what은 들어갈 수 없고, **오직 that만 허용되는 특수 구문과 동격 구조**입니다. 시험에서 빈칸을 뚫어놓고 which를 슬쩍 집어넣어 오답을 유도하는 단골 패턴이죠.
표에 수록된 모든 패턴과 명사들에 맞춰 실전용 예문들을 정리해 드릴게요!

## 1. 너무 ~해서 ~하다 (so / such ~ that 구문)
that 뒤에는 원인에 따른 결과절(완전한 문장)이 연결됩니다.
 * **so + 형용사/부사 + that + 완전한 절**
   * The database query was **so fast that** the application rendered the page instantly.
     (데이터베이스 쿼리가 **너무 빨라서** 애플리케이션이 페이지를 즉시 렌더링했다.)
 * **such + (a/an) + (형용사) + 명사 + that + 완전한 절**
   * It was **such a smooth pencil that** I wrote the entire report without stopping.
     (그것은 **너무 부드러운 연필이어서** 나는 멈추지 않고 보고서 전체를 작성했다.)

## 2. ~해서/~라는 것이 (형용사)하다 & 동격 명사
생각이나 감정을 나타내는 형용사 뒤에 원인을 나타내는 that절, 그리고 특정 명사 뒤에 내용을 보충하는 동격의 that절입니다.
 * **생각/감정 형용사 + that + 완전한 절**
   * I am **sure that** the automated tool will save a lot of time.
     (나는 자동화 도구가 많은 시간을 아껴줄 것이라고 **확신한다**.)
 * **the + 특정 명사 + 동격 that + 완전한 절**
   * The **rumor that** the server crashed turned out to be false.
     (서버가 다운되었다**는 소문**은 거짓으로 밝혀졌다.)

## 3. ~라는 사실/희망 등 명사 (동격의 THAT)
추상명사 뒤에서 뒷문장이 **완전한 절**을 이끌며 구체적인 내용을 설명하는 구조입니다. 이 자리에 which를 쓰면 절대 안 됩니다!
 * **the fact that (~라는 사실)**
   * We cannot ignore **the fact that** asset prices are highly volatile.
     (우리는 자산 가격의 변동성이 크다**는 사실**을 무시할 수 없다.)
 * **the hope that (~라는 희망)**
   * They study late with **the hope that** they will pass the civil service exam.
     (그들은 공무원 시험에 합격할 것이라**는 희망**을 품고 늦게까지 공부한다.)
 * **the idea that (~라는 아이디어/생각)**
   * The developer proposed **the idea that** we should integrate an AI model into the system.
     (개발자는 시스템에 AI 모델을 통합해야 한다**는 아이디어**를 제안했다.)
 * **the news that (~라는 소식)**
   * **the news that** the vaccine program succeeded cheered everyone up.
     (백신 프로그램이 성공했다**는 소식**은 모두를 기쁘게 했다.)
 * **the belief that (~라는 믿음)**
   * He writes with **the belief that** premium stationery improves focus.
     (그는 고급 필기구가 집중력을 높여준다**는 믿음**을 가지고 글을 쓴다.)
 * **the notion that (~라는 개념/생각)**
   * We must challenge **the notion that** programming is only for young people.
     (우리는 프로그래밍이 젊은이들만을 위한 것이라**는 개념**에 도전해야 한다.)
 * **the possibility that (~라는 가능성)**
   * There is **the possibility that** the project deadline will be postponed.
     (프로젝트 마감 기한이 연기될 **가능성**이 있다.)
 * **the perspective that (~라는 관점)**
   * She shares **the perspective that** public services should be fully digitalized.
     (그녀는 공공 서비스가 완전히 디지털화되어야 한다**는 관점**을 공유한다.)
 * **the guarantee that (~라는 보장)**
   * There is no **guarantee that** this trading algorithm will always make a profit.
     (이 트레이딩 알고리즘이 항상 수익을 내 줄 것이라**는 보장**은 없다.)

### 💡 시험장 저격 팁 (What / Which 감별법)
시험 문제에서 the fact [   ] he is honest is true. 같은 문장이 나왔을 때 괄호 뒤를 보세요. he(주어) is(동사) honest(보어)로 문장이 **완전**하죠? 그렇다면 앞의 명사 종류와 상관없이 관계대명사 which는 절대 답이 될 수 없고, 오직 **동격의 that**만 들어갈 수 있습니다.
