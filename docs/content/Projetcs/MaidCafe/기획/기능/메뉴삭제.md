## 개요
메뉴 목록에서 "삭제"를 누르면 확인창을 거쳐 메뉴가 삭제됩니다.

## 동작 방식
확인창에서 승인하면 `features/product-management`가 백엔드의
`DELETE /api/products/:id`를 호출하고, 성공 시 목록에서 해당 메뉴가 즉시
제거됩니다.

## 관련 코드
- `apps/frontend/src/widgets/manage-product-list`
- `apps/frontend/src/features/product-management`
- `apps/backend/src/routes/products.ts` (`DELETE /api/products/:id`)
