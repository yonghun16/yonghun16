## 개요
원재료 소진으로 특정 메뉴를 팔 수 없는 상황을 관리하기 위한 기능이며,
[[메뉴수정품절처리]]의 수동 품절 토글과 함께 씁니다.

**"메뉴별 재고 수량 필드 추가 여부 결정"이 열린 질문이었는데,
상품마다 선택적으로 적용하는 쪽으로 정했습니다** — `Product.stock`은
선택 필드라서, 값을 넣지 않으면 그 메뉴는 지금처럼 재고 개념 없이
수동 품절 토글로만 관리됩니다(예: 즉석으로 만드는 커피/에이드). 값을
넣은 메뉴만 주문마다 자동으로 줄어들고 소진되면 자동 품절됩니다(예:
한정 수량 리미티드 디저트).

## 동작 방식
- **선택적 추적**: 상품 등록/수정 폼의 "재고 수량 (선택)"을 비워두면
  `stock`이 없는 상품이 되어 재고 로직 자체가 적용되지 않습니다. 숫자를
  입력한 상품만 아래 동작이 적용됩니다.
- **자동 차감**: `POST /api/orders`(주문 생성)가 성공하면, 주문에 담긴
  아이템 중 `stock`이 있는 상품만 수량만큼 차감합니다
  (`decrementStockForOrder`). 재고 차감은 주문 생성의 성공/실패와
  분리돼 있어, 차감 중 오류가 나도 손님의 주문 제출 자체는 영향받지
  않고 서버 로그만 남습니다.
- **자동 품절**: 차감 후 재고가 0 이하가 되면 `isSoldOut: true`로
  자동 전환되고, 재고는 0으로 고정됩니다(음수 없음). 고객 화면은 기존
  [[메뉴수정품절처리]]의 품절 표시(흑백 처리, 담기 차단)를 그대로 씁니다
  — 별도 로직 추가 없이 같은 플래그를 재사용.
- **수동 조정**: 관리자 화면의 메뉴 목록에서 재고가 있는 상품에만
  "재고 N개" 표시와 ＋/－ 버튼이 나타나 즉시 1개씩 조정할 수 있습니다
  (`PATCH /api/products/:id/stock`, 절대값 설정). 등록/수정 모달에서도
  숫자를 직접 입력해 한 번에 큰 값으로 바꿀 수 있습니다.
- **재입고 시 자동 품절 해제**: 위 조정 API로 재고를 0보다 크게
  설정하면 `isSoldOut`이 자동으로 `false`로 돌아갑니다 — 재입고했는데
  수동으로 품절을 다시 풀어줘야 하는 번거로움을 없앴습니다.
- **취소 시 자동 복원**: 진행중 주문을 취소하면(`PATCH
  /api/orders/:id/cancel`, [[주문상태전이-API]] 참고)
  `decrementStockForOrder`로 줄였던 만큼을 `restoreStockForOrder`가
  그대로 되돌립니다. 재고가 다시 0보다 커지면 `isSoldOut`도 자동으로
  풀립니다(재입고 때와 같은 규칙). 차감과 마찬가지로 이 복원도 취소
  처리 자체의 성공/실패와 분리된 별도 `try/catch`로 감싸져 있어,
  복원이 실패해도 주문 취소 자체는 이미 반영됩니다.
- 동시 주문으로 인한 차감 레이스 컨디션은 [[주문내역조회]]의
  `orderNumber`와 같은 이유로 감수합니다(1인 매장/저동시성 전제).

## 관련 코드
- `packages/types`의 `Product.stock`(선택 필드), `ProductInput.stock`,
  `UpdateStockInput`
- `apps/backend/src/models/Product.ts` (`stock`, 선택 필드)
- `apps/backend/src/routes/products.ts` — `POST/PUT /api/products`
  (`stock` 포함 가능), `PATCH /api/products/:id/stock`(절대값 설정 +
  자동 품절/해제)
- `apps/backend/src/lib/inventory.ts` — `decrementStockForOrder`
  (주문 생성 후 자동 차감), `restoreStockForOrder`(주문 취소 시 자동
  복원 — `decrementStockForOrder`의 역연산)
- `apps/frontend/src/entities/product/api/productApi.ts`
  (`updateStock`)
- `apps/frontend/src/features/product-management/model/store.ts`
  (`adjustStock`)
- `apps/frontend/src/widgets/add-product-form/ui/AddProductForm.tsx`,
  `apps/frontend/src/widgets/manage-product-list/ui/EditProductForm.tsx`
  (선택 입력 "재고 수량")
- `apps/frontend/src/widgets/manage-product-list/ui/ManageProductList.tsx`
  (재고 표시 + ＋/－ 버튼, `stock`이 있는 상품에만 노출)
