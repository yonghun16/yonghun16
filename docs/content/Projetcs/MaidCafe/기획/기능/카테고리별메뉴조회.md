## 개요
고객이 키오스크 첫 화면(`/`)에서 카테고리 탭을 선택해 해당 카테고리의 메뉴만
걸러볼 수 있는 기능입니다.

## 동작 방식
카테고리는 [[카테고리관리]]에서 관리자가 등록한 목록을 그대로 씁니다
(`order` 순서대로 정렬). 메뉴 목록을 불러오면 **첫 번째 카테고리가 자동으로
선택**되고, 상품 목록을 그 카테고리 기준으로 필터링해 보여줍니다.

과거엔 "전체" 칩이 있어 모든 상품을 한 번에 볼 수 있었지만,
"손님은 전체보기 화면에서 실제로 메뉴를 고르지 않는다"는 실사용 관찰에
따라 제거했습니다 — 항상 특정 카테고리를 먼저 고른 상태에서 메뉴를
보여줍니다(고객 화면 한정. 관리자 화면의 "메뉴 관리" 탭 카테고리 필터에는
"전체"가 그대로 있습니다 — 전체 메뉴를 한눈에 보며 관리해야 하는
관리자 워크플로우와는 목적이 다르기 때문). 위젯이 현재 선택된 카테고리
상태를 관리하고, 실제 상품 데이터와 카드 UI는 `entities/product`를 통해
가져옵니다.
