## 개요
`/admin` 접근 시 관리자 세션이 없으면 로그인 폼을 보여주고, 공유
비밀번호로 로그인하면 관리자 화면(메뉴 등록/삭제)을 쓸 수 있습니다.
역할 구분(점주/직원)은 이번 구현 범위에 포함하지 않았습니다 — "관리자
vs 비관리자" 한 단계만 가릅니다.

## 동작 방식
`AdminPage`가 마운트되면 `GET /api/admin/session`으로 현재 세션의
인증 여부를 확인합니다. 확인 중에는 로딩 문구, 미인증이면 로그인
폼(`LoginForm`)을, 인증되어 있으면 기존 메뉴 등록/삭제 화면과 로그아웃
버튼을 보여줍니다. 로그인 폼에서 비밀번호를 제출하면
`POST /api/admin/login`을 호출하고, 성공하면 관리자 화면으로
전환됩니다. 로그아웃 버튼은 `POST /api/admin/logout`으로 세션을
종료합니다. 주방 화면(`/kitchen`)도 `KitchenPage`에서 같은
`useAdminAuthStore`로 동일한 게이트(로딩 → 로그인 폼 → 화면)를
똑같이 적용합니다 — 별도 권한 분리 없이 `/admin`과 세션을 그대로
공유합니다.
