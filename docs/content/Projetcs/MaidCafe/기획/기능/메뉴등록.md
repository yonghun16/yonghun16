## 개요
관리자가 `/admin` "메뉴 관리" 탭의 **"+ 메뉴 추가" 버튼**을 누르면 뜨는
모달에서 메뉴 이름·가격·이미지·카테고리를 입력해 새 메뉴를 등록합니다.
이미지는 URL을 직접 입력하는 대신 파일을 선택하면 서버에 업로드되고,
반환된 URL이 자동으로 채워집니다.

처음엔 폼이 메뉴 목록 옆에 항상 펼쳐져 있는 형태였는데, 목록을 더 넓게
보여주고 화면을 덜 복잡하게 하기 위해 버튼 클릭 시 여는 모달
(`shared/ui/Modal`)로 바꿨습니다. 등록에 성공하면 모달이 자동으로
닫힙니다(`AddProductForm`의 `onSuccess` 콜백).

## 동작 방식
이미지 파일을 선택하면 즉시 백엔드의 `POST /api/uploads`로 업로드됩니다.
서버가 원본을 그대로 저장하지 않고 리사이즈(가장 큰 변 1600px 이내로
축소, 확대는 안 함) + WebP로 재인코딩한 뒤 Cloudflare R2에 저장하므로,
압축 없이 찍은 큰 사진(예: PNG 2MB)을 올려도 관리자가 직접 압축할
필요 없이 항상 적당한 크기로 맞춰집니다. 반환된 공개 URL이 폼 상태에
채워지며 미리보기가 표시됩니다(업로드 중에는 "업로드 중..." 표시와
함께 제출 버튼이 비활성화됩니다). 이름·가격·이미지 중 하나라도 비어 있으면 안내 메시지가
뜨고 제출되지 않습니다. 등록에 성공하면 폼(이름·가격·이미지)이
초기화되고 메뉴 목록에 즉시 반영되며, 실패하면 폼 입력값은 유지된 채
에러 메시지만 뜹니다. 폼 제출 자체는 이미지 업로드로 받은 URL을 포함해
백엔드의 `POST /api/products`를 호출합니다.

  WebP 재인코딩)
- `apps/backend/src/routes/products.ts` (`POST /api/products`)
