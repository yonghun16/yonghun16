## 개요
고객이 원하는 메뉴 카드를 클릭하면 장바구니에 담기고, 이미 담긴 메뉴를 다시
클릭하면 수량이 1 증가합니다.

## 동작 방식
Zustand 스토어(`features/cart`)가 장바구니 아이템 목록을 관리합니다. 상품
클릭 이벤트가 스토어의 담기 액션을 호출하며, 이미 존재하는 상품이면 수량만
증가시키고 없으면 새 아이템으로 추가합니다.

## 관련 코드
- `apps/frontend/src/features/cart`
- `apps/frontend/src/widgets/product-list`
