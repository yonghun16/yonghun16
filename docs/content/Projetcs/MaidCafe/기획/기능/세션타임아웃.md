## 개요
고객이 장바구니에 메뉴를 담아둔 채 자리를 뜨면, 다음 고객이 이전 고객의
장바구니 상태를 그대로 이어받게 되는 문제가 생깁니다. 세션 타임아웃은
일정 시간 조작이 없을 때 장바구니와 화면 상태를 초기 상태로 되돌려 이런
상황을 방지합니다.

"대기 화면이 필요할까? 고객이 메뉴를 고르다가 그냥 가버리면 다시
프론트 화면으로 넘기는 게 좋지 않을까?"라는 질문으로 시작됐는데, 실제로
필요한 건 프로모션 슬라이드를 보여주는 대기 화면이 아니라 이 세션
타임아웃이었습니다. 대기 화면은 관리자가 별도 홍보 콘텐츠까지 올려야
하는 더 무거운 기능이라 판단을 먼저 답하고, 사용자가 "1분, 경고 없이
바로 초기화"로 요구사항을 확정한 뒤 구현했습니다. 대기 화면 자체는
포트폴리오 범위 밖으로 정리돼 더 이상 백로그에 없습니다.

## 동작 방식
- `HomePage`가 `orderType`이 있는 동안(=매장/포장을 고르고 메뉴 화면에
  들어와 있는 동안)에만 미조작 타이머를 돌립니다. 매장/포장 선택
  화면 자체에는 타이머가 없습니다 — 되돌아갈 "진행 중이던 상태"가
  없기 때문입니다.
- `pointerdown`/`keydown`/`touchstart`/`wheel` 이벤트를 `window`에서
  감지해 타이머를 계속 재시작시킵니다. 마우스 클릭, 터치, 키보드,
  스크롤/휠 중 아무거나 반응하면 타이머가 리셋됩니다(모달 안에서의
  조작도 포함 — `Modal`은 배경 클릭만 막지 `pointerdown`은 막지
  않아서 정상적으로 감지됩니다).
- **1분(`IDLE_TIMEOUT_MS = 60_000`)** 동안 아무 반응도 없으면, **경고
  팝업 없이 바로** `clearCart()`(장바구니 비우기) + `resetOrderType()`
  (매장/포장 선택 화면으로 복귀)을 호출합니다.
- 타이머는 `orderType`이 바뀌거나(다른 손님이 새로 시작) 컴포넌트가
  사라질 때 정리됩니다.

## 모바일 앱(`apps/mobile`) 포팅

웹과 같은 요구사항(1분 무조작 시 초기화)을 React Native 고객용 앱에도
그대로 적용했지만, 감지 방식은 다릅니다. RN에는 웹의
`window.addEventListener` 같은 전역 이벤트가 없고, 특히 옵션 선택/결제
모달은 `<Modal>`로 뜨는 **별도 네이티브 화면**(iOS
`UIViewController`/안드로이드 `Dialog`)이라 최상위 화면에만 감지기를
달면 모달 안 조작을 놓칩니다.

- 타이머 로직을 `shared/lib/idleTimer.ts`에 **모듈 전역 함수**로 뒀습니다
  (React state나 Zustand가 아님) — `shared/ui/Modal`이 FSD 규칙상
  `features/`를 import할 수 없어서, `HomePage`와 `Modal` 양쪽이 같은
  타이머를 공유하려면 이 로직 자체가 `shared/`에 있어야 했습니다.
- 터치 감지는 `onStartShouldSetResponderCapture`(RN 제스처 리스폰더의
  캡처 단계 질의 콜백)를 씁니다. 항상 `false`를 반환해 실제 터치 처리
  (버튼 `onPress` 등)는 자식에게 그대로 넘기고, 호출된다는 사실만
  이용해 부수효과로 타이머를 갱신합니다. `HomePage`의 화면 루트
  `View`와 `shared/ui/Modal`의 오버레이 `View` 양쪽에 달아, 메인 화면
  조작과 모달 안 조작 모두 감지합니다.
- 실기기(에뮬레이터) 확인 중 두 가지를 바로잡았습니다: (1) 웹의
  `onTouchStartCapture`와 이름이 비슷해 처음 시도했으나 RN 타입에는
  없어 컴파일 에러 — `onStartShouldSetResponderCapture`로 교체. (2)
  타임아웃을 6초로 줄여 테스트하던 중 "모달 안 터치가 감지 안 된다"고
  착각했는데, 실제 원인은 메커니즘이 아니라 스크린샷을 읽고 다음
  명령을 내리는 사이(에이전트 처리 시간) 실제 6초가 이미 지나버린
  테스트 방법 문제였습니다 — 탭-대기-탭을 한 셸 명령으로 묶어
  실행하고 나서야 정상 동작을 확인했습니다.

## 관련 코드
- `apps/frontend/src/views/home/ui/HomePage.tsx` (`IDLE_TIMEOUT_MS`
  상수, 미조작 타이머 `useEffect`)
- `apps/frontend/src/features/cart/model/store.ts` (`clearCart` 액션 —
  주문 성공 시와 달리 주문 없이 장바구니만 비우는 용도로 추가)
- `apps/frontend/src/features/order-type` (`resetOrderType`)
- `apps/mobile/src/shared/lib/idleTimer.ts` (모듈 전역 타이머 —
  `startIdleTimer`/`resetIdleTimer`/`stopIdleTimer`)
- `apps/mobile/src/views/home/ui/HomePage.tsx` (`useEffect`로 타이머
  시작/정리, 화면 루트 `View`에 터치 감지)
- `apps/mobile/src/shared/ui/Modal.tsx` (모달 오버레이 `View`에도 동일한
  터치 감지)
