## 개요
[[매출통계대시보드]]가 쓰는 집계 데이터(월별 매출/판매량 추이, 메뉴별
판매 순위)를 계산해 제공합니다. 관리자 화면 전용이라 별도 문서를 새로
만들지 않고, 실제 구현 상세는 [[매출통계대시보드]]의 "동작 방식"/"관련
코드"에 함께 정리했습니다.

## 결정된 범위
- **집계 기준**: 월 단위만(일/주 단위는 범위에 넣지 않음). 완료
  여부와 무관하게 생성된 주문을 집계하되, **취소된 주문(`isCancelled:
  true`)은 제외**합니다 — 취소는 실제로 이뤄지지 않은 판매라 매출로
  잡히면 안 되기 때문입니다([[주문상태전이-API]] 참고. 이 결정 이전에는
  주문 취소 개념 자체가 없어 모든 주문을 그대로 집계했습니다).
- **성능**: 사전 집계 없이 요청마다 실시간 MongoDB 집계
  (`$group`/`$unwind`) — 매장 1곳 규모에서는 충분함.
- **응답 형태**: `GET /api/orders/stats/monthly?year=YYYY`(그 해 1~12월
  추이, 생략하면 올해, 없는 달은 0으로 채움), `GET
  /api/orders/stats/monthly/:month`(그 달의 메뉴별 판매 순위, 판매량
  내림차순). 처음엔 "최근 N개월" 방식이었는데, 프론트에 연도 선택
  필터를 추가하면서 연도 기준으로 바꿨습니다.
