## 개요
장바구니의 각 항목마다 수량을 +/- 버튼으로 개별 조절하고, 삭제 버튼으로
항목을 바로 제거할 수 있습니다. [[장바구니담기]]로 메뉴를 담은 뒤, 이
화면에서 세부 수량을 맞춥니다.

## 동작 방식
주문 목록의 각 항목에 −(감소)/+(증가) 버튼과 🗑(삭제) 버튼이 있습니다.
Zustand 스토어(`features/cart`)의 `increaseQuantity`/`decreaseQuantity`/
`removeFromCart` 액션이 각각 버튼 클릭에 연결되어 있으며, 수량 변경 시
총액도 함께 재계산됩니다.

**모바일 레이아웃**: 처음엔 접이식 요약 카드가 상품 목록 맨 아래(문서
흐름 안)에 있어서, 상품이 많으면 장바구니를 보려고 끝까지 스크롤해야
했습니다. "장바구니가 화면 맨 위 레이어로 하단에 고정돼 있으면
좋겠다"는 요청으로 `position: fixed`(`inset-x-0 bottom-0 z-40`)로
바꿔 항상 화면 하단에 떠 있게 했습니다. 펼쳤을 때 목록 자체는
`max-h-[50vh] overflow-y-auto`로 내부 스크롤만 되게 해서 화면을 넘지
않고, 접혀 있을 때도 화면 맨 아래 일부를 계속 차지하므로 상품 목록
쪽(`ProductList`의 `<main>`)에 `pb-36`(모바일 전용) 여백을 줘서
마지막 상품들이 이 고정 바에 가려지지 않게 했습니다.

## 관련 코드
- `apps/frontend/src/widgets/order-summary/ui/OrderSummary.tsx`
  (모바일 요약 카드 — `fixed inset-x-0 bottom-0 z-40`, 펼친 목록은
  `max-h-[50vh] overflow-y-auto`)
- `apps/frontend/src/widgets/product-list/ui/ProductList.tsx`
  (`<main>`에 모바일 전용 `pb-36` — 고정 장바구니 바에 상품이 가려지지
  않도록 하단 여백 확보)
- `apps/frontend/src/features/cart` (`increaseQuantity`, `decreaseQuantity`,
  `removeFromCart`)
