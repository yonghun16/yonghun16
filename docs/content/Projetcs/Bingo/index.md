# 프로젝트 개요

최대 5명이 함께 즐기는 웹 기반 실시간 멀티플레이어 빙고 게임입니다. 로그인/인증 없이 닉네임만으로 참여하는 프로토타입이며, 별도 게임 서버 없이 Supabase Realtime으로 클라이언트끼리 이벤트를 중계합니다(데이터는 각 클라이언트 로컬 상태가 원본이며 DB에 영구 저장하지 않음, 새로고침 시 초기화).

게임 상태(참가자, 보드, 호출 숫자, 턴, 승패)의 원본 소스는 각 클라이언트이고, Supabase Realtime은 "숫자가 호출됐다" 같은 이벤트만 방 전체에 중계하는 역할만 한다. 자세한 원칙은 [[게임흐름]]의 "실시간 동기화 원칙" 참고.

| 영역 | 스택 | 배포 |
|---|---|---|
| 프론트엔드 | Vite + React + TypeScript + React Router + Tailwind | Vercel (PWA로 설치 가능) |
| 실시간 인프라 | Supabase Realtime (Broadcast + Presence, 별도 서버 코드 없음) | Supabase 관리형 프로젝트 |

# 게임 방법

1. **방 만들기**: 타이틀 화면에서 보드 크기(3x3/4x4/5x5/6x6/7x7)를 고르고 방을 만들면 고유 room ID와 초대 링크가 생성된다. 카톡 등에 공유하면 방장 닉네임과 보드 크기가 반영된 미리보기 카드가 뜬다.
2. **입장**: 다른 유저는 링크로 접속해 닉네임을 입력하고 입장한다. 정원은 최대 5명이며, 이미 게임이 시작된 방에는 입장할 수 없다(원래 참가자의 재접속은 예외).
3. **빙고판 세팅**: 좌(보드 크기에 맞는 빙고판) / 우(실시간 채팅, 모바일에서는 하단 플로팅 버튼으로 여닫는 바텀시트) 화면에서 1~(가로세로 칸수)² 숫자를 중복 없이 전부 배치하면 "준비 완료" 처리된다. "무작위로 채우기" 버튼으로 한 번에 채울 수도 있다. 최소 2명 이상 전원이 준비를 마치면 자동으로 게임이 시작된다.
4. **게임 진행(턴제)**: 입장 순서대로 턴을 가지며, 현재 턴 유저는 자신의 빙고판에서 칸을 직접 눌러 10초 안에 아직 불리지 않은 숫자를 호출한다. 시간 초과 시 방장(호스트) 클라이언트가 남은 숫자 중 랜덤 자동 호출. 숫자가 호출되면 전원의 보드에서 해당 숫자가 자동 마킹되고, 남은 시간은 원형 뱃지로 크게 표시된다.
5. **승리 조건**: 보드 크기별로 필요한 완성 줄 수가 다르다(3x3=1줄 ~ 7x7=5줄, [[게임흐름]]의 표 참고). 동시 달성 시 공동 우승.
6. **게임 종료**: 우승 즉시 게임이 끝나고 전원의 보드가 공개되며(우승자 보드는 황금색으로 강조), "다시 하기"로 같은 방에서 새 게임을 시작하거나 "새 게임 만들기"로 타이틀 화면으로 돌아갈 수 있다.
7. **채팅**: 게임 시작 전/후 언제든 닉네임 + 메시지 + 타임스탬프 형식으로 채팅할 수 있다. 새 메시지는 화면 상단 토스트로도 잠깐 표시된다.

자세한 스펙은 [[게임흐름]] 문서를 참고한다.
