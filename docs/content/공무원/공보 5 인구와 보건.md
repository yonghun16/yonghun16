# [Theme 05] 인구와 보건 80점 목표 족집게 요약

## 1. Blacker의 인구 변천 5단계
* 1단계: 다산다사 (인구정지)
* 2단계: 다산감사 (**인구폭발**, 사망률 저하)
* 3단계: 감산소사 (인구증가 둔화)
* 4단계: 소산소사 (인구정지)
* 5단계: 인구감소기 (출생 < 사망)

## 2. 재생산 지표 및 공식
* **합계출산율(TFR):** 가임여성 한 명이 평생 낳는 평균 자녀 수.
* **순재생산율(NRR):** 여아 수에 모체의 사망률 반영.
  - $NRR = 1$: 인구 정지
  - $NRR > 1$: 인구 증가
* **성비:** 여자 100명당 남자 수.
  - 1차: 수정 시 / 2차: 출생 시 / 3차: 현재 인구 성비.

## 3. 인구구조 유형 (0~14세 vs 65세 이상)
* **피라미드형:** $0 \sim 14$세 $>$(65세 이상$\times 2$) [인구 증가]
* **종형:** $0 \sim 14$세 $=$(65세 이상$\times 2$) [인구 정지]
* **항아리형:** $0 \sim 14$세 $<$(65세 이상$\times 2$) [인구 감소]
* **별형(도시형):** 15~64세 인구가 50% 초과. (유입형)
* **기타형(농촌형):** 15~64세 인구가 50% 미만. (유출형)

## 4. 인구 지수 공식
* **총부양비:** $(유년 + 노년) / 생산연령인구 \times 100$
* **노령화지수:** $노년인구 / 유년인구 \times 100$
* **성비:** $남자인구 / 여자인구 \times 100$

## 5. 고령화 사회 분류 (65세 이상 비율)
* 7% 이상: 고령화 사회 (Aging Society)
* 14% 이상: 고령 사회 (Aged Society)
* 20% 이상: 초고령 사회 (Super-aged Society)


# [인구와 보건] 100점 만점 방지용 초지엽 디테일 요약

## 1. 인구이론 심화 (Beyond Malthus)
* **스펜서(Spencer):** 자기 유지를 위한 지적 능력이 발달할수록 생식력은 저하됨.
* **더블데이(Doubleday):** 단백질 등 풍부한 영양 섭취가 생식력을 감소시킴.
* **1974 부쿠레슈티 회의:** "개발이 최고의 피임약" (경제 발전 강조).

## 2. 인구 통계 및 성비 디테일
* **상주인구(De jure):** 한국 인구주택총조사의 표준. 거주지 중심.
* **2차 성비:** 출생 시 성비 (여아 100명당 남아 수, 105~106이 정상).
* **유아여성비(CWR):** $(0 \sim 4세 아동 / 15 \sim 49세 가임여성) \times 1,000$.
* **종속비(Dependency Ratio):** 부양비라고도 함. 생산연령인구($15 \sim 64$)가 분모.

## 3. 생명표(Life Table) 기호 암기
* $l_x$: 생존수 (Survival)
* $d_x$: 사망수 (Death)
* $q_x$: 사망률 (Probability of death)
* $L_x$: 정지인구 (Stationary population)
* $e_x$: 기대여명 (Life expectancy). $e_x = T_x / l_x$
* **기대수명:** 0세 시점의 기대여명($e_0$).

## 4. 샌드버그(Sandberg) 지수
* 공식: $(50세 이상 인구 / 0 \sim 14세 인구) \times 100$
* 해석: 
  - 60 미만: 건강 수준 높음 (젊은 인구)
  - 90 초과: 건강 수준 낮음 (늙은 인구)

## 5. 인구 변천 단계 (Blacker) 킬러 포인트
* **2단계(초기확장기):** 사망률이 출생률보다 '먼저' 떨어져서 인구가 **급증**하는 단계.
* **5단계(감퇴기):** 출생률이 사망률보다 낮아져 절대 인구가 **감소**하는 단계.
