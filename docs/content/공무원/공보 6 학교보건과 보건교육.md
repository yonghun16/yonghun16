# [Theme 06] 학교보건과 보건교육 80점 목표 족집게 요약

## 1. 보건교육 방법 (핵심 구분)
* **브레인스토밍:** 아이디어 폭발, 비판 금지, 수정 및 결합 가능.
* **심포지엄:** 전문가 발표 + 전문가 토론 (전문적 지식 전달).
* **패널 토의:** 상반된 의견의 배심원(Panel) 토론.
* **버즈 세션:** 6-6법칙, 소집단 토의 후 전체 공유.
* **역할극:** 태도 변화, 역지사지 경험.

## 2. 보건교육 평가의 시기
* **진단평가:** 교육 전 (출발점 행동 파악).
* **형성평가:** 교육 진행 중 (피드백, 방법 수정).
* **총괄평가:** 교육 종료 후 (목표 달성도 평가).

## 3. 교사 내 환경위생 기준 (필수 암기 수치)
* **온도:** 18~28°C (적정 범위).
* **조도:** 300lux 이상 (교실 책상면).
* **이산화탄소($CO_2$):** 1,000ppm 이하 (오염 지표).
* **소음:** 55dB(A) 이하 (교실 안).

## 4. 학교보건 인력 및 감염병 관리
* **보건교사 배치:** 18학급 이상인 학교는 의무 배치.
* **등교 중지:** 학교장이 결정, 출석 인정 처리.
* **학교보건의 중요성:** 인구의 약 1/4이 학생, 교육의 효과가 가정과 지역사회로 파급됨.

## 5. 보건교육 이론 (핵심만)
* **건강신념모형(HBM):** 질병에 걸릴 가능성(지각된 민감성)과 심각성을 인지해야 행동이 변함.
* **학습 이론:** 지식(Cognitive) -> 태도(Affective) -> 실천(Psychomotor)의 변화 과정.


# [100점 완성] 학교보건 및 보건교육 초지엽 디테일 요약

## 1. PRECEDE-PROCEED 모델 진단 단계 (교육적 진단)
* **소인(성향)요인:** 지식, 태도, 믿음, 가치관 (개인 내부).
* **가능(촉진)요인:** 기술, 자원, 가용성, 접근성 (개인 외부 환경).
* **강화요인:** 주변의 보상, 칭찬, 비난, 사회적 지지 (피드백).

## 2. 학생건강체력평가(PAPS) 필수 항목
* **심폐지구력:** 왕복 오래달리기, 스텝검사.
* **유연성:** 앉아 윗몸 앞으로 굽히기.
* **근력/근지구력:** 악력, 윗몸 말아 올리기.
* **순발력:** 제자리멀리뛰기, $50\,m$ 달리기.
* **체지방:** $BMI$, 체지방률($BIA$).

## 3. 학교 실내 공기질 세부 수치
* **미세먼지:** $PM_{10} \le 75$, $PM_{2.5} \le 35$.
* **이산화질소($NO_2$):** $0.05\,ppm$ 이하.
* **일산화탄소($CO$):** $9\,ppm$ 이하.
* **라돈:** $148\,Bq/m^3$ 이하.

## 4. 학교 환경위생 설비 기준
* **창면적:** 교실 바닥 면적의 $1/5$ 이상.
* **자연조명:** 바닥 면적의 $1/10 \sim 1/4$ 정도가 적당.
* **조도균제도:** (최대조도:최소조도) = $3:1$ 이내 유지.

## 5. 보건교육 학습 이론의 변화 과정
* **지식(Knowledge) -> 태도(Attitude) -> 실천(Practice)**
* **KAP 모델:** 지식이 있다고 해서 바로 실천으로 옮겨지지 않으며, 중간에 '태도(신념)'의 변화가 반드시 필요함을 강조.

## 6. 보건교육 평가의 질적 요건
* **신뢰도를 높이는 법:** 문항 수를 늘린다, 문항의 난이도를 적절히 조절한다, 시험 범위를 좁힌다(일관성 확보).
* **타당도:** 측정 목적과의 부합 여부.
