# 최소공배수(LCM) 자세히 설명

## 1. 최소공배수가 뭔지부터

**LCM(a, b)** = a와 b의 공통 배수 중 **가장 작은 수**

### 예: lcm(12, 18) 구하기

**12의 배수**: 12, 24, 36, 48, 60, 72, ...
**18의 배수**: 18, 36, 54, 72, ...
**공통 배수**: 36, 72, 120, ...
**최소공배수**: **36**

## 2. 공식: lcm(a, b) = (a × b) / gcd(a, b)

### 왜 이 공식이 성립하나?

#### 소인수분해로 이해하기

```
12 = 2² × 3¹
18 = 2¹ × 3²

GCD(12, 18) = 2¹ × 3¹ = 6  (공통 지수의 최솟값)
LCM(12, 18) = 2² × 3² = 36 (공통 지수의 최댓값)
```

**핵심 관찰**:
```
12 × 18 = (2² × 3) × (2 × 3²)
        = 2³ × 3³  
        = 216

GCD(12, 18) = 2 × 3 = 6

LCM(12, 18) = (12 × 18) / GCD(12, 18)
            = 216 / 6
            = 36
```

### 직관적 이해

```
12 × 18 = 216

이건 2를 한 번 중복으로 곱한 것 (2¹이 2번)
그리고 3을 한 번 중복으로 곱한 것 (3¹이 2번)

GCD(12, 18) = 6은 바로 이 중복 부분!
따라서 216을 6으로 나누면 중복을 제거 → LCM
```

## 3. 단계별 계산 예제

### lcm(12, 18) 구하기

**Step 1: GCD 구하기**
```
gcd(12, 18):
18 = 12 × 1 + 6
12 = 6 × 2 + 0
→ gcd(12, 18) = 6
```

**Step 2: 공식 적용**
```
lcm(12, 18) = (12 × 18) / gcd(12, 18)
            = 216 / 6
            = 36
```

**Step 3: 검증**
```
36 ÷ 12 = 3 ✓ (12의 배수)
36 ÷ 18 = 2 ✓ (18의 배수)
36 < 72, 36 < 54 ✓ (가장 작은 공통 배수)
```

## 4. 다른 예제들

### lcm(8, 12)

**소인수분해로**:
```
8 = 2³
12 = 2² × 3

lcm = 2³ × 3 = 24
```

**공식으로**:
```
gcd(8, 12):
12 = 8 × 1 + 4
8 = 4 × 2 + 0
→ gcd = 4

lcm(8, 12) = (8 × 12) / 4
           = 96 / 4
           = 24
```

### lcm(7, 11) - 서로소인 경우

```
7과 11은 소수이므로 gcd(7, 11) = 1

lcm(7, 11) = (7 × 11) / 1
           = 77 / 77
           = 77
```

**특징**: 서로소면 lcm = a × b

## 5. 코드로 구현

```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

def lcm(a, b):
    return (a * b) // gcd(a, b)

# 사용 예
print(lcm(12, 18))  # 36
print(lcm(8, 12))   # 24
print(lcm(7, 11))   # 77
```

## 6. 왜 a × b를 먼저 계산?

**중요**: 순서가 있습니다!

```python
# ❌ 잘못된 순서 (오버플로우 가능)
result = (a * b) // gcd(a, b)

# ✅ 큰 수에는 이렇게
result = a // gcd(a, b) * b  # 또는
result = b // gcd(a, b) * a
```

예를 들어 a=1000000, b=999999라면:
- a × b는 엄청 크지만
- a // gcd(a,b)는 작으니까 먼저 나누고 곱하면 오버플로우 방지

## 8. 실제 활용

### 분수 덧셈
```python
# 1/12 + 1/18 = ?
a_num, a_den = 1, 12
b_num, b_den = 1, 18

common = lcm(a_den, b_den)  # lcm(12, 18) = 36
result_num = a_num * (common // a_den) + b_num * (common // b_den)
# = 1 × 3 + 1 × 2 = 5
result_den = common  # 36

# 답: 5/36
```
