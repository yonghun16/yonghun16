## 1. 수학적 원리 (왜 작동하는가?)

### 핵심 성질
**gcd(a, b) = gcd(b, a mod b)**

이게 왜 성립하는지 증명해보겠습니다.

a = b × q + r (q는 몫, r은 나머지)라고 하면:

- a의 약수 중 b도 나누는 것 = b의 약수 중 r도 나누는 것
- 왜냐하면 r = a - b × q이므로
- d가 a와 b를 모두 나누면, d는 r도 나눈다
- 역으로 d가 b와 r을 나누면, d는 a = b × q + r도 나눈다

따라서 a와 b의 공약수 집합 = b와 r의 공약수 집합
→ **최대공약수도 같다!**

### 구체적 예제: gcd(48, 18)

```
Step 1: 48 = 18 × 2 + 12
        48과 18의 공약수 = 18과 12의 공약수
        
Step 2: 18 = 12 × 1 + 6
        18과 12의 공약수 = 12와 6의 공약수
        
Step 3: 12 = 6 × 2 + 0
        12와 6의 공약수 = 6과 0의 공약수
        
Step 4: b = 0이므로 종료
        gcd(48, 18) = 6
```

## 2. 왜 반복할 때마다 수가 줄어드나?

**핵심**: 나머지는 항상 제수(b)보다 작다

```
a = b × q + r  (0 ≤ r < b)
```

따라서:
- gcd(a, b) → gcd(b, r)로 변환할 때
- 새로운 a는 기존 b
- 새로운 b는 기존 r < 기존 b
- 수가 지수적으로 감소!

## 3. 시간복잡도 심화

**왜 O(log min(a, b))인가?**

연속된 두 나머지를 보면:
```
r₁ = a mod b
r₂ = b mod r₁
r₃ = r₁ mod r₂
...
```

**라메의 정리**: 
- n단계 이내에 종료
- n ≤ 5 × (b의 자릿수)
- 피보나치 수열과 밀접한 관련

**최악의 경우**: 연속된 피보나치 수
```
gcd(F(n), F(n-1))는 가장 많은 단계 필요
예: gcd(89, 55) → 약 10단계
```

## 4. 단계별 추적 (gcd(100, 35))

| 단계 | a | b | 계산 | 나머지 |
|------|-----|-----|-------------|--------|
| 0 | 100 | 35 | 100 = 35×2 + 30 | 30 |
| 1 | 35 | 30 | 35 = 30×1 + 5 | 5 |
| 2 | 30 | 5 | 30 = 5×6 + 0 | 0 |
| 3 | 5 | 0 | **종료** | **GCD = 5** |

## 5. 코드별 상세 해석

### Java (반복)
```java
int gcd(int a, int b) {
    // b가 0이 아닌 동안 계속
    while (b != 0) {
        int temp = b;      // 다음 단계의 a 준비
        b = a % b;         // 다음 단계의 b (나머지)
        a = temp;          // a를 업데이트
    }
    // b = 0일 때 a가 GCD
    return a;
}
```

### Python (재귀 - 더 깔끔)
```python
def gcd(a, b):
    # 기저사건: b = 0이면 a가 답
    if b == 0:
        return a
    # 재귀: gcd(b, a mod b) 호출
    return gcd(b, a % b)
```

### Python 한 줄 (삼항연산자)
```python
def gcd(a, b):
    return a if b == 0 else gcd(b, a % b)
```

## 6. 응용 예제

### LCM(최소공배수) 구하기
```python
def lcm(a, b):
    return (a * b) // gcd(a, b)

# 예: lcm(12, 18) = 36
# 12 = 2² × 3
# 18 = 2 × 3²
# lcm = 2² × 3² = 36
```

### 분수 기약분수로 약분
```python
def reduce_fraction(num, den):
    g = gcd(num, den)
    return num // g, den // g

# 예: 48/18 = 8/3
reduce_fraction(48, 18)  # (8, 3)
```

## 7. 확장 유클리드 호제법 (심화)

ax + by = gcd(a, b)를 만족하는 **정수 x, y를 찾기**

```python
def extended_gcd(a, b):
    if b == 0:
        return a, 1, 0  # gcd, x, y
    else:
        gcd_val, x1, y1 = extended_gcd(b, a % b)
        x = y1
        y = x1 - (a // b) * y1
        return gcd_val, x, y

# 예: gcd(48, 18) = 6
# 48 × (-1) + 18 × 3 = 6 확인!
```

**활용**: 모듈러 역원 계산, RSA 암호화 등
