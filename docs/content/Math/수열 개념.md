## 수열의 정의 

수열은 **자연수 집합 ℕ을 정의역으로 하는 함수**입니다.

> f: ℕ → ℝ, aₙ = f(n)

즉 각 자연수 n에 하나의 수 aₙ을 대응시킨 것이고, 이를 차례로 나열한 a₁, a₂, a₃, …, aₙ, … 을 수열이라 하며 {aₙ}으로 나타냅니다.

**용어**
- **항**: 수열을 이루는 각각의 수
- **첫째항**: a₁
- **일반항**: 제n항 aₙ (수열 전체를 결정하는 식)
- **유한수열 / 무한수열**: 항이 유한개인지 무한히 계속되는지에 따라 구분

**예시**
- aₙ = 2n → 2, 4, 6, 8, … (등차수열)
- aₙ = 2ⁿ → 2, 4, 8, 16, … (등비수열)
- aₙ = (−1)ⁿ → −1, 1, −1, 1, … (진동하는 수열)

고교 교과과정에서는 간단히 "차례대로 나열된 수의 열"로 소개하지만, 엄밀하게는 위처럼 정의역이 자연수인 함수로 봅니다.


## 수열의 유형 (일반항)
수열의 규칙을 찾는 게 핵심이고, 유형별로 방법이 달라요.

**1. 등차수열** (차이가 일정)
- aₙ = a₁ + (n − 1)d
- 예: 3, 7, 11, 15 → a₁ = 3, d = 4 → aₙ = 4n − 1

**2. 등비수열** (비가 일정)
- aₙ = a₁ · rⁿ⁻¹
- 예: 2, 6, 18, 54 → a₁ = 2, r = 3 → aₙ = 2 · 3ⁿ⁻¹

**3. 계차수열** (이웃한 항의 차이가 규칙을 가짐)
- bₙ = aₙ₊₁ − aₙ 이면 aₙ = a₁ + Σₖ₌₁ⁿ⁻¹ bₖ (n ≥ 2)
- 예: 1, 2, 4, 7, 11 → 차이 1, 2, 3, 4 → aₙ = 1 + n(n−1)/2

**4. 합 Sₙ이 주어질 때**
- a₁ = S₁, aₙ = Sₙ − Sₙ₋₁ (n ≥ 2)
- 마지막에 n = 1을 넣어 a₁과 맞는지 꼭 확인하세요.

**5. 점화식이 주어질 때**
- aₙ₊₁ = aₙ + d → 등차, aₙ₊₁ = r·aₙ → 등비
- aₙ₊₁ = p·aₙ + q 꼴은 aₙ₊₁ − α = p(aₙ − α)로 바꿔 등비수열로 만듭니다 (α = q/(1−p)).
- 막히면 a₁, a₂, a₃ …을 직접 나열해 규칙을 찾는 것도 좋은 방법이에요.

**6. 분수·부호가 섞인 경우**
- 분자와 분모를 따로 보고 각각 일반항을 구합니다.
- 부호가 번갈아 바뀌면 (−1)ⁿ 또는 (−1)ⁿ⁺¹을 곱해요.
