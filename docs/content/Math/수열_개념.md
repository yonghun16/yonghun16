## 수열의 개념

**수열의 정의**

수열은 **자연수 집합 ℕ을 정의역으로 하는 함수**입니다.

> f: ℕ → ℝ, aₙ = f(n)

즉 각 자연수 n에 하나의 수 aₙ을 대응시킨 것이고, 이를 차례로 나열한 a₁, a₂, a₃, …, aₙ, … 을 수열이라 하며 {aₙ}으로 나타냅니다.

**용어**
- **항**: 수열을 이루는 각각의 수
- **첫째항**: a₁
- **일반항**: 제n항 aₙ (수열 전체를 결정하는 식)
- **유한수열 / 무한수열**: 항이 유한개인지 무한히 계속되는지에 따라 구분

**예시**
- aₙ = 2n → 2, 4, 6, 8, … (등차수열)
- aₙ = 2ⁿ → 2, 4, 8, 16, … (등비수열)
- aₙ = (−1)ⁿ → −1, 1, −1, 1, … (진동하는 수열)

고교 교과과정에서는 간단히 "차례대로 나열된 수의 열"로 소개하지만, 엄밀하게는 위처럼 정의역이 자연수인 함수로 봅니다.
