**수열의 극한(수렴)의 정의 (ε-N 정의)**

수열 {aₙ}이 L로 수렴한다는 것은:

> 임의의 양수 ε > 0에 대하여, 자연수 N이 존재해서
> n ≥ N 이면 |aₙ − L| < ε 이 성립한다.

이때 lim(n→∞) aₙ = L 이라고 씁니다.

**직관적 의미**
- ε은 "얼마나 가까워야 하는지" 정하는 오차 범위예요.
- 아무리 작은 ε을 잡아도, 어느 항(N번째) 이후로는 모든 항이 L의 ε 범위 안에 들어온다는 뜻입니다.

**예시: aₙ = 1/n → 0**
- ε이 주어지면 N > 1/ε인 자연수 N을 잡습니다.
- n ≥ N이면 |1/n − 0| = 1/n ≤ 1/N < ε 이므로 성립.

**참고**
- 고교 교과과정에서는 "n이 한없이 커질 때 aₙ이 L에 한없이 가까워진다"로 정의합니다.
- 수렴하지 않으면 **발산**이며, 양의 무한대·음의 무한대로 발산하거나 **진동**할 수 있습니다.
