## 개요

핵심은 한 문장입니다. 상한(sup)은 상계 중 가장 작은 값이고, 하 한(inf)은 하계 중 가장 큰 값이며, 그 값이 집합 안에 들어 있으면 최댓값·최솟값이 됩니다. 이 글에서는 실수의 부분집합 S를 다룹니다.

|   |   |   |
|---|---|---|
|용어|영어|한 줄 정의|
|상계|upper bound|S의 모든 원소보다 크거나 같은 수|
|하계|lower bound|S의 모든 원소보다 작거나 같은 수|
|위로 유계 / 아래로 유계|bounded above / below|상계 / 하계가 존재함|
|유계|bounded|위로도 아래로도 유계|
|최댓값|maximum|S에 속하는 상계|
|최솟값|minimum|S에 속하는 하계|
|상한|supremum, sup|상계 중 가장 작은 수(최소상계)|
|하한|infimum, inf|하계 중 가장 큰 수(최대하계)|

상계·하계는 존재만 하면 되고 S 안에 있을 필요가 없습니다. 최댓값·최솟값은 반드시 S 안에 있어야 합니다. 이 차이가 이 단원에서 가장 많이 헷갈리는 지점입니다.

## 정의

집합 S ⊂ ℝ (S는 공집합이 아님)이라 하겠습니다.

**1. 상계와 하계**

- 실수 M이 S의 상계: 모든 x ∈ S에 대해 x ≤ M
- 실수 m이 S의 하계: 모든 x ∈ S에 대해 m ≤ x

```latex
M \text{ 은 } S \text{ 의 상계} \iff \forall x \in S,\ x \le M
```

```latex
m \text{ 은 } S \text{ 의 하계} \iff \forall x \in S,\ m \le x
```

**2. 유계**

- 위로 유계: 상계가 하나라도 존재
- 아래로 유계: 하계가 하나라도 존재
- 유계: 위로도 아래로도 유계. 동치 조건은 "어떤 K > 0이 있어 모든 x ∈ S에 대해 |x| ≤ K"입니다.

**3. 최댓값과 최솟값**

- 최댓값 max S: S의 상계이면서 S의 원소인 수
- 최솟값 min S: S의 하계이면서 S의 원소인 수

```latex
M = \max S \iff M \in S \ \text{이고} \ \forall x \in S,\ x \le M
```

**4. 상한과 하한**

- 상한 sup S: 상계들의 집합에서 가장 작은 원소(최소상계)
- 하한 inf S: 하계들의 집합에서 가장 큰 원소(최대하계)

동치 표현 (증명에서 가장 많이 쓰는 ε 판정법)입니다.

```latex
\alpha = \sup S \iff \begin{cases} (\text{i}) & \forall x \in S,\ x \le \alpha \\ (\text{ii}) & \forall \varepsilon > 0,\ \exists x \in S \ \text{s.t.}\ x > \alpha - \varepsilon \end{cases}
```

```latex
\beta = \inf S \iff \begin{cases} (\text{i}) & \forall x \in S,\ x \ge \beta \\ (\text{ii}) & \forall \varepsilon > 0,\ \exists x \in S \ \text{s.t.}\ x < \beta + \varepsilon \end{cases}
```

(i)은 α가 상계라는 뜻이고, (ii)는 α보다 조금이라도 작은 수는 더 이상 상계가 아니라는 뜻입니다. 즉 α가 가장 작은 상계라는 조건을 풀어 쓴 것입니다.

**참고: 용어 대응.** 한국어 교재에 따라 "상한/하한"을 sup/inf 대신 "upper bound/lower bound"의 번역으로 쓰는 경우가 있습니다. 이 자료는 상계·하계 = bound, 상한·하한 = sup·inf로 구분합니다.

## 핵심 정리

**정리 1. 완비성 공리(최소상계 성질).** ℝ의 공집합이 아닌 부분집합이 위로 유계이면, 상한이 ℝ 안에 존재합니다. 마찬가지로 아래로 유계이면 하한이 ℝ 안에 존재합니다.

이 성질이 ℝ과 ℚ를 가르는 결정적 차이입니다. 예를 들어 ℚ의 부분집합 {x ∈ ℚ : x² < 2}는 위로 유계이지만 ℚ 안에서는 상한이 없습니다. 상한이 √2인데 √2는 유리수가 아니기 때문입니다.

**정리 2. 최댓값과 상한의 관계.**

- 최댓값이 존재하면 그 값이 곧 상한입니다. 즉 max S = sup S.
- 반대로 sup S ∈ S이면 sup S가 최댓값입니다.
- sup S ∉ S이면 S에는 최댓값이 없습니다. 상한은 있어도 최댓값은 없는 경우입니다.

하한과 최솟값도 똑같이 성립합니다.

**정리 3. 유일성.** 상한과 하한은 존재하면 유일합니다. 상계는 무수히 많지만 최소상계는 하나뿐이기 때문입니다. 따라서 최댓값·최솟값도 존재하면 유일합니다.

**정리 4. 유계성의 동치 조건.** 다음은 서로 동치입니다.

1. S는 유계이다.
2. 어떤 K > 0이 있어 모든 x ∈ S에 대해 |x| ≤ K이다.
3. S는 구간 [a, b]에 포함된다.

**정리 5. 부분집합과 상한.** A ⊂ B이고 B가 위로 유계이면 A도 위로 유계이며 다음이 성립합니다.

```latex
\sup A \le \sup B, \qquad \inf A \ge \inf B
```

집합이 커지면 상한은 커지고 하한은 작아진다는 직관과 일치합니다.

**정리 6. 부호 반전.** −S = {−x : x ∈ S}라 하면 다음이 성립합니다.

```latex
\sup(-S) = -\inf S, \qquad \inf(-S) = -\sup S
```

상한에 대한 증명을 하한으로 옮기고 싶을 때 이 관계를 쓰면 됩니다.

**정리 7. 아르키메데스 성질(상한의 응용).** ℕ은 ℝ에서 위로 유계가 아닙니다. 완비성 공리와 모순을 이용해 증명하며, 결과적으로 임의의 양수 ε에 대해 1/n < ε인 자연수 n이 존재합니다.

## 예시

여섯 가지 집합을 같은 기준으로 비교합니다. 핵심 관찰은 맨 아래 두 열입니다. 상한·하한은 모두 존재하지만 최댓값·최솟값이 있는지는 집합마다 다릅니다.

|   |   |   |   |   |   |
|---|---|---|---|---|---|
|집합 S|유계 여부|sup S|inf S|max S|min S|
|[0, 1]|유계|1|0|1|0|
|(0, 1)|유계|1|0|없음|없음|
|[0, 1)|유계|1|0|없음|0|
|{1/n : n ∈ ℕ}|유계|1|0|1|없음|
|ℕ = {1, 2, 3, …}|아래로만 유계|없음(위로 유계 아님)|1|없음|1|
|ℤ|유계 아님|없음|없음|없음|없음|

**예 1. 열린구간 (0, 1).**

- 상계 전체의 집합은 [1, ∞)이므로 최소상계는 1입니다. 따라서 sup = 1.
- 하계 전체의 집합은 (−∞, 0]이므로 최대하계는 0입니다. 따라서 inf = 0.
- 1과 0은 S에 속하지 않으므로 최댓값·최솟값은 없습니다.

**예 2. S = {1/n : n ∈ ℕ} = {1, 1/2, 1/3, …}.**

- 모든 원소가 1 이하이고 1 ∈ S이므로 max S = sup S = 1.
- 모든 원소가 0보다 크므로 0은 하계입니다. 어떤 ε > 0이든 1/n < ε인 n이 있으므로 (아르키메데스 성질) 0보다 큰 수는 하계가 될 수 없습니다. 따라서 inf S = 0.
- 0 ∉ S이므로 최솟값은 없습니다.

**예 3. S = {x ∈ ℚ : x² < 2}.**

ℝ에서 보면 sup S = √2, inf S = −√2이고 둘 다 S에 속하지 않습니다. 정리 1에서 말한 대로 ℚ만 놓고 보면 상한이 존재하지 않는 집합입니다.

**예 4. 합집합 S = [0, 1] ∪ {5}.**

- max S = 5 (5는 S의 원소이면서 상계)
- min S = 0
- 구간 부분은 [0, 1]이지만 상한은 1이 아니라 5입니다. 합집합의 상한은 각 부분 집합의 상한 중 큰 쪽입니다.

**예 5. 수열의 상한 — a_n = (−1)ⁿ(1 + 1/n).**

수열을 값들의 집합 {a_n : n ∈ ℕ}으로 보면 a₁ = −2, a₂ = 3/2, a₃ = −4/3, a₄ = 5/4, … 입니다.

- 짝수 번째 항은 3/2, 5/4, 9/8, …로 줄어들며 최댓값은 a₂ = 3/2입니다. 홀수 번째 항은 −2, −4/3, …로 −1에 가까워집니다.
- 따라서 max = 3/2, min = −2 (a₁). 이 수열은 최댓값과 최솟값이 모두 존재합니다.

## 자주 하는 실수와 증명 요령

**자주 하는 실수**

1. 상한과 최댓값을 같은 것으로 착각한다. (0, 1)의 상한은 1이지만 최댓값은 없습니다.
2. 상계는 하나뿐이라고 생각한다. 상계는 무수히 많고, 그중 가장 작은 것이 상한입니다.
3. "유계 ⇒ 최댓값 존재"라고 착각한다. 유계여도 최댓값이 없을 수 있습니다.
4. 상한이 항상 S의 원소라고 생각한다. 원소일 수도 있고 아닐 수도 있습니다.
5. 공집합의 상한을 따진다. 공집합은 모든 실수가 상계이므로 최소상계가 존재하지 않습니다. 정의에서 S ≠ ∅를 가정하는 이유입니다.
6. 합집합의 상한을 구간의 끝점으로만 판단한다. 예 4처럼 흩어진 점이 상한을 결정할 수 있습니다.

**sup = α임을 보이는 두 단계**

1. α가 상계임을 보인다. 모든 x ∈ S에 대해 x ≤ α.
2. α가 최소상계임을 보인다. 임의의 ε > 0에 대해 α − ε이 상계가 아님을, 즉 x > α − ε인 x ∈ S가 있음을 보인다.

**inf = β임을 보이는 두 단계**는 방향만 바꾸면 됩니다. β가 하계이고, 임의의 ε > 0에 대해 x < β + ε인 x ∈ S가 존재함을 보입니다.

**체크리스트**

- 최댓값이 있는지 물으면 → 상한을 구한 뒤, 그 값이 S에 속하는지 확인한다.
- 상한을 구하라고 하면 → 상계 후보를 찾고, ε 판정법으로 최소임을 확인한다.
- 합집합·부분집합·부호 반전이 나오면 → 정리 5, 6을 먼저 떠올린다.
- 유계임을 보이라고 하면 → |x| ≤ K인 K를 하나만 찾으면 된다.

## 연습문제와 풀이

**문제 1.** 다음 집합의 sup, inf, max, min을 구하세요 (없으면 "없음").

- (a) A = [−2, 3)
- (b) B = {x ∈ ℝ : x² ≤ 4}
- (c) C = {1 − 1/n : n ∈ ℕ}
- (d) D = {x ∈ ℝ : x > 0}

**문제 2.** S = {n/(n+1) : n ∈ ℕ}의 상한이 1임을 ε 판정법으로 증명하세요.

**문제 3.** A, B가 모두 공집합이 아니고 위로 유계일 때, A ∪ B의 상한이 max(sup A, sup B)임을 보이세요.

**문제 4.** ℕ이 위로 유계가 아님을 완비성 공리로 증명하세요.

**문제 5. (참/거짓)** "S가 유계이면 sup S ∈ S이다." 판정하고 반례 또는 증명을 쓰세요.

---

**풀이 1.**

- (a) sup A = 3, inf A = −2, max A 없음, min A = −2
- (b) B = [−2, 2]이므로 sup B = max B = 2, inf B = min B = −2
- (c) C = {0, 1/2, 2/3, 3/4, …}. sup C = 1, inf C = min C = 0 (n = 1일 때), max C 없음
- (d) D = (0, ∞)는 위로 유계가 아니므로 sup 없음. inf D = 0, min D 없음

**풀이 2.** 각 항 n/(n+1) = 1 − 1/(n+1) < 1이므로 1은 상계입니다. 이제 임의의 ε > 0을 잡으면 아르키메데스 성질에 의해 1/(n+1) < ε인 n이 있고, 이때 n/(n+1) = 1 − 1/(n+1) > 1 − ε입니다. 따라서 1 − ε은 상계가 아니고, sup S = 1입니다. (S에 1은 속하지 않으므로 최댓값은 없습니다.)

**풀이 3.** α = max(sup A, sup B)라 두겠습니다.

1. 상계: x ∈ A이면 x ≤ sup A ≤ α, x ∈ B이면 x ≤ sup B ≤ α. 따라서 α는 A ∪ B의 상계입니다.
2. 최소: 임의의 ε > 0에 대해, 예를 들어 α = sup A라면 A에 x > α − ε인 원소가 있고, 이 x는 A ∪ B에도 속합니다. α = sup B인 경우도 같습니다.

따라서 sup(A ∪ B) = α입니다.

**풀이 4.** ℕ이 위로 유계라고 가정하면 완비성 공리에 의해 α = sup ℕ이 존재합니다. α − 1은 상계가 아니므로 n > α − 1인 n ∈ ℕ이 있습니다. 그러면 n + 1 > α이고 n + 1 ∈ ℕ이므로 α가 상계라는 사실에 모순입니다. 따라서 ℕ은 위로 유계가 아닙니다.

**풀이 5.** 거짓입니다. S = (0, 1)은 유계이지만 sup S = 1 ∉ S입니다.
