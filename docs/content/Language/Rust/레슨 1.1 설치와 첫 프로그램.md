## 레슨 1.1: 설치와 첫 프로그램

### 1. rustup 설치

Rust는 `rustup`이라는 도구로 설치하고 버전을 관리합니다.

- **macOS / Linux / WSL**
    
    ```bash
    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
    ```
    
- **Windows**: https://rustup.rs 에서 `rustup-init.exe`를 받아 실행 (C++ 빌드 도구가 필요하다는 안내가 나오면 따라 설치)

설치 후 터미널을 새로 열고 확인합니다.

```bash
rustc --version
cargo --version
```

### 2. cargo로 프로젝트 만들기

`cargo`는 Rust의 빌드 도구이자 패키지 매니저입니다. Java의 Maven/Gradle, C의 make와 비슷한 역할인데, 훨씬 간단합니다.

```bash
cargo new hello_rust
cd hello_rust
```

생성되는 구조는 이렇습니다.

```
hello_rust/
├── Cargo.toml    # 프로젝트 메타데이터와 의존성 (package.json 같은 것)
└── src/
    └── main.rs   # 진입점
```

`src/main.rs`를 열면 이미 코드가 들어 있습니다.

```rust
fn main() {
    println!("Hello, world!");
}
```

### 3. 실행해 보기

```bash
cargo run
```

### 4. 코드 뜯어보기

- `fn main()`은 C의 `main`처럼 프로그램 시작점입니다. 반환 타입이 없으면 "아무것도 반환하지 않음"입니다.
- `println!`의 **`!`는 매크로 호출 표시**입니다. 함수가 아니라 매크로라서 `!`가 붙습니다. 지금은 "출력 함수 비슷한 것"으로만 이해해도 됩니다.
- 문장 끝에는 `;`을 씁니다. 이게 나중에 "표현식 vs 문장" 얘기에서 중요해집니다.
- 들여쓰기는 스페이스 4칸이 관례입니다.

### 5. 자주 쓰는 cargo 명령어

|명령|역할|
|---|---|
|`cargo run`|빌드 후 실행|
|`cargo build`|빌드만 (`target/debug/`에 생성)|
|`cargo build --release`|최적화 빌드 (`target/release/`)|
|`cargo check`|컴파일 가능 여부만 빠르게 검사 (실행 파일 안 만듦)|
|`cargo test`|테스트 실행|

개발 중에는 `cargo check`를 습관적으로 쓰세요. 전체 빌드보다 훨씬 빨라서 컴파일러와 대화하는 속도가 올라갑니다.

## 연습 문제

`main.rs`를 아래처럼 바꿔서 직접 실행해 보세요.

```rust
fn main() {
    println!("안녕하세요, {}입니다!", "여기에 이름");
    println!("Rust 학습 {}일차", 1);
}
```

그다음 아래 세 가지를 시도해 보세요.

1. `{}` 자리에 들어갈 값을 하나 지우고 `cargo run` 해 보기 (에러 메시지가 어떻게 나오는지 읽어 보기)
2. 첫 번째 `println!` 줄 끝의 `;`을 지우고 `cargo check` 해 보기
3. `cargo build --release`로 빌드한 뒤 `target/release/` 안에 실행 파일이 생겼는지 확인
